# HIL 工作台改良：候选发布报告

> 历史记录：首次 HIL 改良候选交付。下文“本轮/现役/尚未”属于当时阶段，后续版本与现状见 [STATUS](STATUS.md)；保留原结果和未验收边界。
本轮交付软件和候选包，现场验收按用户要求另约。现役 F1 遥操 v15、工作台 v23 未切换，未启动实机输出或重启驱动/相机；只读核对 F1-09 machine-id 和现役 HIL 空闲。

## 实现范围

- 工作台：颜色/图标/短标签、共享三图预览、帧身份/年龄、停拉与取消、折叠配置及本地回放。HIL目标10fps，其他页约1.33fps。
- 运行端：约5Hz后台结构化状态、会话用途/模型配置固定、policy-shadow、过期成功与异常先检查epoch。控制锁、START/RB/Home、相机频率和原保护阈值不变。
- 策略：GET health能力合同、multipart process_frame、模型版本绑定；网页探活/新观测试推理；显式假模型/可替换加载函数的服务器模板。
- 视频：正常会话提交后持久任务；服务器下载已校验片段帧、H.264三图时间线、回传校验和Range播放。单任务2MiB/s限速，活动HIL/数采暂停传输。重试/崩溃租约恢复/部分文件续传；审核与训练就绪独立。
- 组织：F1/G2最外层分离保留，公共层新增无机器人控制依赖的三图渲染器。工作台使用独立可部署的合同副本，与F1版本按字节一致测试。

## 尚未验收

- 候选运行端的 ARM 数值/依赖检查、真实反馈 shadow，以及现场F710操作。
- 预览开/关各至少10分钟的30Hz真实采集与ACK对照；本次未重复此现场试验。此前短测只能说明当时未见持续降频，不等于本候选已现场验证。
- 多可见浏览器窗口的现场链路开销、镜头到屏幕延迟、真实模型并发推理延迟。
- 真实模型权重与服务器地址/worker凭证配置；当前提供完整接口、模板和假服务，未绑定实际模型。
- 既有100–250ms偶发采集间隔仍作为独立问题保留，未靠改采集频率/补帧/放宽watchdog处理。

视频前后文不足时据实截断；异常退出未提交的partial只保留原始证据，不自动生成“完整视频”。视频审核“采纳”不是训练审核文件，训练仍需要原导出审计与人工批准。G2现役冻结目录和启动脚本不改写。

## 发布与回退

候选清单绑定所有代码、配置模板和文档SHA，F1依赖清单只更新已改相机元数据的adapter源码SHA，模型/关节映射资产不改。发布包仅在开发机准备并验证，不修改机器current/dev或原启动脚本。

现场另约后按：ARM离线 → 真实反馈shadow → 正在操作的负载对照 → 工作台/运行端分批切换 → 配置服务器worker。切换前备份当前版本、配置、dev和服务，保留v15/v23回退入口。任何服务切换需工作台空闲，不能用停止驱动或其他遥操强行接管。
