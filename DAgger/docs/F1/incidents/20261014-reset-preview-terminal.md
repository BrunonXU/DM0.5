## 根因与离线对照

复用实际IK、250Hz输出平滑器、原限位，使用日志姿态离线复现：模拟上抬至57.722658mm后输出停住，距目标60mm差2.277420mm；原2mm到位检查不放行，模拟19.02秒超时。奇异值约0.165、速度缩放1.0，没有奇异减速。输出模式为limit_braking且remaining_s=0；右腕J6=41.686984度、J7=-67.770841度，处于既有 `1.025*abs(J6)+abs(J7)<=110.5度` 组合边界。IK虚拟目标仍领先输出约1.718873度。

已经完整结束的认证轨迹，其终端目标速度、加速度本为零，但Ruckig多项式求值留下约1e-17速度及1e-16加速度的浮点残值。下一次请求Phase同步时因此退化为Time曲线，腕部组合在中途超界约0.000161107度，被连续轨迹认证正确拒绝，继而重复使用已经结束的刹停轨迹。时间延长不能消除这个固定点。

同一静止终点的四组对照：原残值+Time、原残值+Phase、精确零+Time均被连续限位认证拒绝；精确零+Phase通过，原腕组合限位丝毫未放宽。此对照说明关键在终态表达与同步，而非增大容差。

## 修复

仅当 `elapsed >= trajectory.duration` 时，用该条认证轨迹本就要求的精确零速度、零加速度表达完成状态；保留原终点位置，不在运动中清动量、不重置当前位置、不改任何限位/到位/速度/加速度/jerk参数。所有下一条轨迹继续接受完整连续限位认证，无法认证仍刹停。

独立脚本新增preview_failed及phase字段，预演失败明确打印“尚未发送机器人动作”，与实机运行错误区分。现场提示改为避让允许少量姿态变化，不增加独立转腕动作。

无碰撞模块的初步数值对照已走过lift→right→return；正式验收另用实际CollisionGate、原姿态和完整脚本preview，并回归动态边界、旧失败起点、Y重试与连续示教保存。最终测试、部署及现场验收事实以[STATUS](../STATUS.md)为准，不能用数值预演宣称真机到位。
