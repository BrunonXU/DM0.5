# 2026-10-13 F710训练导出过度切段修正

本次修正开发机离线导出和F1-infra统一数据适配。原始录制只读，修复前源码保留；没有切换机器人release、修改采集/控制参数或执行真机动作。此前审计中的48/41/21段是旧导出实现的真实结果，不能改写历史记录。

## 根因

`select_segments`先按真实观测间隔、相机回调连续性、来源epoch/接管、Home及新鲜度筛选有效组，再用30Hz最近邻网格取样。第二步要求每格最近实测观测误差不超过半周期且不能重复使用索引，否则立即切段。稍慢于30Hz或有抖动的连续采集不能一直满足这两个条件。三条任务候选第二步前有17/7/11组，之后却成为48/41/21段；不是发生了相应次数的真实断流。

另有次要问题：旧网格累加`round(1e9/fps)`，会积累纳秒级偏差；循环还允许超过最后观测半周期。新实现分别从有理周期计算各格点，并截止最后有效观测。

## 修复与时间含义

采样版本为`causal_observation_hold_and_published_action_v2`。为兼容现有固定fps LeRobot数据与动作delta_timestamps，本次采用固定30Hz网格，不另造尚未接入RLinf的变长时间reader：

- 每格只选当时已经可用的最近有效整组图像/state，不选未来观测。必要时沿用旧观测，保留原始图像字节、反馈值、观测ID/时间、相机身份和时间戳。
- action独立从该网格时刻之前最后有效`submitted`命令取值，连同命令序号、发布来源时间保留；沿用图像不代表沿用旧动作，禁止用反馈回填。
- 在网格时刻重新验证原有命令50ms、反馈250ms、相机200ms及观测间隔1.5周期的要求，不放宽保护。不跨相机不连续、Home、无效发布、接管或epoch变化；无效格仍切段，绝不删格后压缩时间。
- `reference_monotonic_ns`/统一数据`time_ns`表示采样格点；`source_observation_monotonic_ns`表示真实观测可用时间，`observation_age_ns`表示沿用年龄，`observation_reused`标明同一段内再次使用同一观测。统计分开记录网格样本数与唯一来源数，不能宣称新增曝光帧。
- 统一适配器保留以上来源信息。审核增加`selection_sha256`，新版F710拒绝用旧分段编号批准新分段。训练发布允许单一导出内有记录的沿用，但禁止不同相位/帧率的导出重复使用同一来源观测。

这是保留原始时间证据的有界观测保持，不是把短片段直接首尾拼接，也不是认证相机曝光同步。
