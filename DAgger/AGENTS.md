# DAgger Agent 工作约定

适用于 DAgger 全树。用户当前授权优先；先读本文件、[文档索引](docs/README.md) 和涉及机器的当前状态。工作区协作规则见 `../PROJECT_RULES_AND_PREFERENCES.md`；本文给出本项目可独立执行的要求。

## 入口与文档

- 根 README 给人类，只保留功能与入口；F1/G2/teleop README 简短介绍用途和配置位置。详细启动、配置、原理和验收统一在 `docs/`，不要新增 `doc/` 或平台下的第二份 docs。
- F1 当前事实只维护 [docs/F1/STATUS.md](docs/F1/STATUS.md)；G2 当前事实只维护 [docs/G2/RECORDING_AND_PROGRESS.md](docs/G2/RECORDING_AND_PROGRESS.md)。其他页面链接这些来源，不复制一套“当前状态”。
- 日期记录中的结论保留原时点，补证写清真实日期和来源；不以文件mtime猜日期。说明可短，推导、失败证据、原始记录和数据不得删。精确重复正文合一，有独有补证先合并再去重。
- 移动文档同步修索引、相对链接和开发机命令。机器人不可变release的历史路径保持原意，不能按开发树机械替换。文档提及原路径/哈希不代表仍存在第二套开发源码。
- 启动说明要给全机器、终端、工作目录和日志位置。F1/G2 DAgger 必须给隧道、Windows sender、机器人现场三个终端；不要只发机器人 powered 命令。

## 目录与依赖

| 目录 | 责任 |
|---|---|
| `F1/` | f1dagger、16D合同、机器配置、脚本、服务和测试 |
| `G2/` | g2dagger、34D合同、机器配置、脚本和测试 |
| `G2/teleop/` | 独立F710遥操、诊断、模型与冻结基线 |
| `shared/` | 无机器人导入的 dagger_core 和公共测试 |
| `docs/` | 当前操作、架构和完整历史说明 |
| `artifacts/` | 数据、日志、结果、归档、缓存；不入Git、不进源码包 |

F1/G2 只能向 shared 依赖；公共层不导入机器人实现或承担机器人关节映射。不要把 F1 的度数/夹爪0–100和 G2 的34D合同混用。根 `pyproject.toml` 管理两平台和公共测试。

`g2_robot`、DM0.5、F1-infra、LeRobot 与厂商 ROS/GDK 是独立依赖，不属于此次收口范围。先核对路径、源码/模型绑定和运行环境，再复用最小必要能力；不能重新复制整个外部仓库。已有env/SDK/ARM产物不直接跨架构搬用。

## 开发与验证

1. 先查现有源码和证据，沿已验证基线推进。保留用户未提交改动，不擅自commit、不使用reset --hard清工作区。
2. 从 DAgger 根用已验证解释器执行 `python -m pytest`；改动局部时先测受影响模块。独立teleop按其文档单独测。依赖缺失、skipped和实现失败分别报告，不改保护或测试断言来掩盖环境问题。
3. 改路径/打包时，在无旧src/doc/common/G2Teleop兼容树的临时目录解包，验证导入、只读help/inspect和清单。检查无越界软链接、无原始数据/凭据/venv/旧副本入包。
4. 文档变化检查所有当前MD链接；不改 `artifacts/` 下不可变报告、原始日志或归档内容。可以新增迁移清单、README和验证结果。
5. 先定位根因，再改参数。不得擅加滤波、冻结手部、阈值或固定运行时长来遮盖问题；保留已验证硬件保护。对照实验尽量只改一个变量。
6. 报告区分源码/本地离线、ARM数值、真实反馈shadow、现场动作、训练认证。配置目标频率不是实测频率，发布成功不是实物到位。

## 机器人与数据

真机动作由现场操作者执行，确认使用Enter和既有START；不新增文字口令，不通过SSH远程启动动作。授权的只读核对、打包、传输、备份与明确部署按任务范围推进，不把例行可逆工作变成重复询问。

保留唯一输出owner、跨进程锁、机器/驱动/模型合同、ACK/session/epoch、反馈新鲜度、watchdog和明确接管语义。不得删锁、杀其他任务来强抢控制。独立teleop与HIL不能并行输出，浏览器/传输连接成功不代表动作已授权。

G2不改系统包。F710接收器接Windows，原厂常驻joystick程序误动作事故仍适用。G2最后记录为维修暂停；没有维修/验收新证据时不得写成已恢复。

F1明确配置 `F1_INFRA_ROOT`、`F1_PROFILE_PATH`、共用 `F1_CONTROL_LOCK` 和机器runtime。三路线、旧v15入口及当前运行端的关系以STATUS为准；整理源代码不会切换机器人release。

原始图像、日志和采集数据只读保留，审核/预览/导出另存。区分policy proposal、human candidate、selected、submitted、SDK结果与measured，不用反馈回填action。结构完整不等于training_ready；`.partial`、shadow、Home或失败段不能直接当专家数据。

## 发布与回退

- F1从根运行 `python3 F1/scripts/53_package_f1.py --output <新包路径>`；包固定公共组件，只含本平台。开发树和独立发布包目录映射见ARCHITECTURE。
- G2沿用本机已验证打包/安装合同，不能将本地重排自动套到实机。优先定向传明确文件，不做删除式同步清理其他目录。
- 发布前保存实际旧release、配置、入口、服务和现场修改，记录SHA；上传后核对清单和依赖。失败保留旧入口，切换只在本任务空闲时做，不停止驱动/其他遥操来强行接管。
- 保留可回退版本；代码回退不恢复姿态，不删除新数据，不重放旧命令。每个包的文档是打包时快照，当前状态另在唯一状态页维护。
- 原 `data/logs/results` 已归 `artifacts`；原顶层冻结源码和原G2Teleop已在archive完整归档。不得恢复旧树作为第二套活跃开发入口。
