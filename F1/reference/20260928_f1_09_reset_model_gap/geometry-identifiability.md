# 剩余双臂几何差异：可辨识性审查

2026-09-28。仅离线读取原始URDF、已留存16组原生FK响应和原生DH配置；未连接机器人，未修改应用、原URDF、网格、驱动或动作接口。

**结论：剩余差异确实包含随姿态变化的关节轴几何差异，不能用未知的固定基座／法兰坐标变换消除。但末端FK并不能唯一决定每个URDF连杆坐标原点及网格应放在哪里；也不能证明哪一份名义模型符合实物。**

## 不依赖绝对坐标系的证据

以下量只取旋转轴线的最近距离和共同法线沿轴方向的间距，固定基座、法兰和TCP变换均不会改变它们。URDF原始RPY保留了四舍五入，造成约0.0023mm级偏差。

| 轴几何不变量 | 原生DH左右臂 | 网页URDF左臂 | 网页URDF右臂 |
|---|---:|---:|---:|
| J3、J4旋转轴最近距离 | 18mm | 0mm | 18mm |
| J4、J5旋转轴最近距离 | 18mm | 0.0023mm（近似0） | 17.9977mm（近似18） |
| 沿J3轴的J2/J4共同法线间距 | 287mm | 287mm | 287mm |
| 沿J5轴的J4/J6共同法线间距 | 314mm | 311mm | 311.0001mm |

因此，可以确认左侧两个横向18mm差异、两侧纵向3mm差异属于两份模型之间的机构轴几何差异，不是仅仅选错base或TCP坐标系。

## 独立原生FK样本检验

取已记录的每臂8组非退化虚拟输入，允许未知固定基座平移和法兰／工具平移。固定基座旋转来自此前独立的角轴比较，未用位置数据调整。仅优化固定基座／工具平移时：

| 模型 | 左臂位置RMS / 最大差 | 右臂位置RMS / 最大差 |
|---|---:|---:|
| 原URDF，允许固定base/tool偏移 | 18.904 / 26.834mm | 1.927 / 2.285mm |
| 另允许joint4.x、joint5.x、joint5.y变化 | 0.00255 / 0.00444mm | 0.00229 / 0.00411mm |

受限三参数模型解得：

- 左臂：joint4.x **+17.99974mm**，joint5.x **+17.99949mm**，joint5.y **−3.00094mm**。
- 右臂：joint4.x约0、joint5.x约0、joint5.y **−2.99944mm**。
- 分别去掉一组样本拟合、再预测被去掉的样本，最大预测差左0.00717mm、右0.00651mm；不是单姿态拟合。

这些结果准确解释了与原生DH之间的名义差异。数值是模型间一致性证据，不是现场几何测量精度。

## 哪些参数可以定位，哪些不能

固定其他关节轴方向、只允许URDF原点平移时，把全部7关节×3轴共21个平移分量纳入，投影掉固定base/tool的影响后，只有11个稳健可辨识方向，剩余10个方向属于坐标原点分配或近似不可辨识。URDF有限RPY小数产生1e−5级的伪独立方向；按1e−4奇异值阈值处理，避免用百万毫米补偿去解释微米级舍入误差。

- **左joint4.x和joint5.x的横向18mm分量可在现有轴方向、合理尺度的原点平移模型中稳定定位**；对应旋转轴的最近距离也独立证明了差异。以当前URDF坐标约定补这两处18mm，是对齐原生DH的直接候选。
- **纵向3mm差异能确认，但不能只靠末端FK唯一指定必须写在joint5.y。**把joint5.y减少3mm，或在joint6.z增加3mm，都能得到同样的下游轴几何和末端结果。后一模型的拟合残差同样只有约0.00255mm左、0.00229mm右。
- 两种纵向分配对末端近似等价，却会决定`arm_*_Link5`本身的网格是否移动。因此，不能仅以“和SDK算得一样”为理由移动link5/STL。
- 上述可辨识结论固定了已有轴方向和标定角定义；不是任意改轴、改零偏或改连杆定义情况下的全局唯一性证明。

## 支持的下一步与缺少的资料

可以立即把上述两份模型差异和候选修正写入统一配置对照／审计合同，明确“SDK名义几何对齐候选”，并给出纯离线对照。**本报告不支持未经补充依据就把原网格改成“已校准实物模型”。**

要发布为全身实物一致模型，至少需要：

1. F1-09实际左、右臂型号或厂家适用范围说明，确认两臂都应采用当前`ccs_m6_40.MvKDCfg`的18/314mm名义结构，而不是拿一份可能不适配实物的DH作为唯一真值。
2. 对应版本CAD／URDF导出的link坐标定义，尤其`arm_*_Link5`、joint5、joint6，以及STL网格相对于这些坐标原点的位姿。这决定纵向3mm应分配到哪个origin，是否还需移动视觉／碰撞网格。
3. 若没有厂家资料，需要以电机轴心／法兰作为可重复测量基准的实物尺寸或多姿态测量；不能用单张透视照片估算毫米级修正。
4. 全身的肩基座安装位姿、身体和头部零偏／轴方向仍需各自证据。当前双臂FK样本不覆盖它们，也不验证平衡或碰撞安全。
