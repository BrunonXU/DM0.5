## 此次记录的结论

用户报告标准全身复位后网页左手较高、实物左手也略高。标准 `pose_2` 的双臂目标与 LXL XY 相同，是工作姿态，不能解释为编码器标零或全部角度归零。

理想目标下，原始 URDF 左、右 Link7 原点相对 `body_Link5` 的 Z 分别为 80.577857 / 56.423904 mm，差 **24.153954 mm**。该姿态躯干与底盘 Z 方向一致。左 joint4/5 的 origin.x 在内存副本各补 18 mm 后，差为 −0.002409 mm；16 组原生 FK 与轴线距离证据支持存在模型间几何差异。原生 DH 在名义共同安装变换下预测两侧 TCP 等高，但它含工具偏移，与 Link7 原点不同。**以上均不等于实测夹爪高度或真机定位误差，候选几何未部署。** 两侧另有 311/314 mm 尺寸差异，末端 FK 不能唯一确定纵向 3 mm 应分配到哪个连杆原点。

15:28 全身复位成功和 15:29 无运动到位确认有事件证据；旧版没有保存当时完整 22 轴实测，不能用后来的积木姿态反馈回填。1° 关节到位容差也不是物理末端精度。短期保持当前目标与几何，在相同底盘/工装/工具条件下通过现场观察确认固定 demo 能正常重复；精确 TCP、IK、碰撞/仿真或实物偏差影响任务时再开展机构与标定核验。
