## 排障与停用

在 F1 的 user 终端执行：

```bash
systemctl --user status f1-6000d-tunnel.service --no-pager
loginctl show-user user -p Linger
tail -n 80 /home/user/Bruno/connect/tunnel.log
ip route get 10.130.153.114
```

显式停用（会断开隧道连接）：`systemctl --user disable --now f1-6000d-tunnel.service`。
恢复：`systemctl --user enable --now /home/user/Bruno/connect/systemd/f1-6000d-tunnel.service`。
完整回退本次 Linger 变更时，先确认没有其他需驻留的用户服务，再执行 `loginctl disable-linger user`。
撤销 6000D 授权时只移除 `f1-22029-reverse-tunnel` 对应公钥行，不能覆盖其他密钥。
6000D 初始备份为 `~/.ssh/authorized_keys.before_f1_22029_20260918T091640Z`。
