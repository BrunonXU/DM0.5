# F1系统接口清单

### 1. 启动相关及电机控制

```bash
/home/user/workspace/f1-system-readme
```

#### 使用说明

将电机及手臂调至指定位置

---

通过/home/user/workspace/start_all.sh 启动所有ros节点

---

脚本在~/workspace/f1/test 目录

starts的三个起始位置需要读取 /hal/joint_states中

- body_j3
- body_j4
- body_j5

这三个关节的数据，需要通过脚本，进行平滑控制，避免直接通过ros发送较大的关节变化

```bash
python3 ros2_joint_control.py --motors 5,6,7 --starts="-4,-20,-12" --
ends="-2,-6,-5" --duration 10
```

---

调节双臂至工作位，可以直接发送ros接口，关节角度可以有较大变化

```bash
ros2 topic pub /motion_ctl/joint_ctl sensor_msgs/msg/JointState "{ header:
{stamp: {sec: 0, nanosec: 0}, frame_id: 'base_link'}, name: ['arm_l_j1','arm_l_j2','arm_l_j3','arm_l_j4','arm_l_j5','arm_l_j6','arm_l_j7','arm_r_j1','arm_r_j2','arm_r_j3','arm_r_j4','arm_r_j5','arm_r_j6','arm_r_j7'
], position: [90.0, -90.0, -90.0, -90.0, 0.0, 0.0, 0.0, -90.0, -90.0, 90.0,-90.0, 0.0, 0.0, 0.0], velocity: [], effort: []}" --once
```

配置ec主站的开机自启动service

```ini
/etc/systemd/system/ec-master.service
[Unit]
Description=EC-Master Service
After=network.target
[Service]
```

```ini
Type=simple
User=root
ExecStartPre=/bin/sleep 10
ExecStart=/home/user/workspace/start_ec_master.sh
Restart=on-failure
RestartSec=10
StandardOutput=append:/var/log/ec-master.log
StandardError=append:/var/log/ec-master.log
[Install]
WantedBy=multi-user.target
```

#### 3.5 灵巧手控制

参考“关节控制”

说明：

position字段表示手指弯曲的百分比，取值范围是[0.0, 100.0]，0.0是手指不弯曲，只需要变更关节名称：

hand_l_thumb # 左手拇指弯曲

hand_l_index # 左手食指弯曲

hand_l_middle # 左手中指弯曲

hand_l_ring # 左手无名指弯曲

hand_l_little # 左手小指弯曲

hand_l_thumb_rot # 左手拇指摆动

hand_r_thumb # 右手拇指弯曲

hand_r_index # 右手食指弯曲

hand_r_middle # 右手中指弯曲

hand_r_ring # 右手无名指弯曲

hand_r_little # 右手小指弯曲

```python
def send_command(motor_id, target_angle, seq=1, host='127.0.0.1', port=50001):
"""
# 发送UDP控制命令
"""
fmt = '<I B f f f I'
velocity = 0.0
acceleration = 0.0
crc = 0
data = struct.pack(fmt, seq, motor_id, target_angle, velocity,acceleration, crc)
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.sendto(data, (host, port))
sock.close()
print(f"[SEND] motor_id={motor_id}, angle={target_angle}°, seq={seq}")
print(f" data={data.hex()}")
def send_multiple_commands(commands, host='127.0.0.1', port=50001,
delay_ms=50):
for i, (motor_id, angle) in enumerate(commands):
send_command(motor_id, angle, seq=i+1, host=host, port=port)
if delay_ms > 0 and i < len(commands) - 1:
time.sleep(delay_ms / 1000.0)
```
