# 通用机器人软件接口文档

## 一. 关于上位机的DDS配置需求

### 1. 使用DDS的版本

目前下列接口的开发是基于ubuntu22.04和humble版本的ros2系统开发的，其中我司使用的DDS为 Cyclone DDS，具体版本信息如下所示：

```bash
sunrise@ubuntu:~$ dpkg -l | grep cyclonedds
ii ros-humble-cyclonedds 0.10.5-2jammy.20260307.131623 arm64 Eclipse Cyclone DDS
is a very performant and robust open-source DDS implementation.
ii ros-humble-rmw-cyclonedds-cpp 1.3.4-1jammy.20260307.175012 arm64 Implement the ROS
middleware interface using Eclipse CycloneDDS in C++.
```

当使用上位机调用ros2接口的时候，需要确保以下三项的一致性：

  - 默认DDS的方式为Cyclone DDS(echo $RMW_IMPLEMENTATION 指令查询当前使用的DDS方式)
  - DDS版本要求:0.10.5
  - Cyclone DDS的cyclonedds.xml使用和我司一致的格式，修改网口为实际上位机使用的网口

这样才能保障通讯的稳定和准确，具体配置DDS的操作可以参考 DDS详细配置流程

## 二. Steward模块

### 1. 数据上传接口

#### 1.1 异常上传

##### 1.1.1 接口名

- steward/alarm/Data : 机器人异常上传

##### 1.1.2 接口形式

- Topic(20Hz)

##### 1.1.3 功能描述

- 接口用于机器人异常上传。

##### 1.1.4 消息类型

- 类型: steward/AlarmsData

##### 1.1.5 消息字段

- header(std_msgs/Header): 消息头信息
  - stamp (builtin_interfaces/Time): 时间戳
  - frame_id (string): 坐标系 ID
- alarms(steward/AlarmData[]):
  - start_time(builtin_interfaces/Time):异常发送时间
  - level(uint8):异常级别
  - error_code(uint32):异常码
  - error_msg(string):异常描述
  - sensor_id(uint8):传感器编号
  - sensor_error(uint32):传感器本体异常码
  - duration(uint32):异常持续时间

##### 1.1.6 使用示例

```python
#!/usr/bin/env python3
import rclpy
from steward.msg import AlarmsData
def main():
rclpy.init()
node = rclpy.create_node('simple_alarms_subscriber')
def callback(msg):
node.get_logger().info(f'Received {len(msg.alarms)} alarm(s)')
for alarm in msg.alarms:
node.get_logger().info(f' Level: {alarm.level} | Code: {alarm.error_code} | Msg:
{alarm.error_msg} | '
f'SensorID: {alarm.sensor_id} | SensorErr:
{alarm.sensor_error} | '
f'Duration: {alarm.duration}s'
)
# Create subscriber
node.create_subscription(AlarmsData, 'steward/alarm/Data', callback, 10)
try:
rclpy.spin(node)
except KeyboardInterrupt:
pass
finally:
node.destroy_node()
rclpy.shutdown()
if __name__ == '__main__':
main()
```

##### 1.1.1 接口名

- driver/lidar/lidar_name/imu/Data : 多个雷达lidar_name名称不一致,依据urdf文件定

义

##### 1.1.2 接口形式

- Topic(200Hz)

##### 1.1.3 功能描述

- 接口用于提供激光雷达内置 IMU（惯性测量单元）信息，包括线性加速度和角速度。

##### 1.1.4 消息类型

- 类型: sensor_msgs/Imu

##### 1.1.5 消息字段

- header(std_msgs/Header): 消息头信息
  - stamp (builtin_interfaces/Time): 时间戳
  - frame_id (string): 坐标系 ID
- orientation: 方向四元数
  - x , y , z , w (float64): 四元数的分量
- orientation_covariance: 方向协方差矩阵 (float64[9])
- angular_velocity: 角速度
  - x , y , z (float64): 角速度的分量
- angular_velocity_covariance: 角速度协方差矩阵 (float64[9])
- linear_acceleration: 线性加速度
  - x , y , z (float64): 加速度的分量
- linear_acceleration_covariance: 加速度协方差矩阵 (float64[9])

#### 据urdf文件定义

##### 1.2.2 接口形式

- Topic(10Hz)

##### 1.2.3 接口描述

- 接口用于提供激光雷达的点云数据信息，用于三维空间的点云表示。

##### 1.2.4 消息类型

- 类型: sensor_msgs/PointCloud2

##### 1.2.5 消息字段

- header(std_msgs/Header): 消息头信息
  - stamp (builtin_interfaces/Time): 时间戳
  - frame_id (string): 坐标系 ID
- height (uint32): 点云的高度（通常为 1）
- width (uint32): 点云的宽度（点的数量）
- fields: 点字段信息
  - name (string): 字段名称
  - offset (uint32): 字段偏移

#### datatype (uint8): 数据类型

  - count (uint32): 字段计数
- is_bigendian (bool): 是否为大端序
- point_step (uint32): 每个点的字节数
- row_step (uint32): 每行的字节数
- data (uint8[]): 点云数据
- is_dense (bool): 是否为密集点云

##### 1.2.6 使用示例

```python
#!/usr/bin/env python3
import rclpy
from sensor_msgs.msg import PointCloud2
DATATYPE_MAP = {
1: 'F64', 2: 'U64', 3: 'I64',
4: 'F32', 5: 'U32', 6: 'I32',
7: 'U16', 8: 'I16', 9: 'U8', 10: 'I8'
}
def main():
rclpy.init()
node = rclpy.create_node('get_lidar_pointcloud_data')
def pointcloud_callback(msg):
# Message header info
tSec = msg.header.stamp.sec
tNanosec = msg.header.stamp.nanosec
# Coordinate frame
sFrameId = msg.header.frame_id
# Point cloud width and height
uiPointCloudHeight = msg.height
uiPointCloudWidth = msg.width
# Bytes per point
uiPointStep = msg.point_step
# Bytes per row
uiRowStep = msg.row_step
# Whether the point cloud is dense
bDense = msg.is_dense
# Whether the data is big-endian
bBigendian = msg.is_bigendian
# Fields info
fields_list = []
for field in msg.fields:
dtype_str = DATATYPE_MAP.get(field.datatype, 'UNK')
fields_list.append(f"{field.name}({field.offset}:{dtype_str})")
sFields = "[" + ", ".join(fields_list) + "]"
# === Final output ===
node.get_logger().info(f'Frame: {sFrameId} | Time: {tSec}.{tNanosec:09d} | '
f'Width: {uiPointCloudWidth} | Height: {uiPointCloudHeight} | '
f'PointStep: {uiPointStep}B | RowStep: {uiRowStep}B | '
f'IsDense: {bDense} | Bigendian: {bBigendian} | '
f'Fields: {sFields}'
)
# lidar_name should match the URDF definition
sub = node.create_subscription(PointCloud2,'driver/lidar/lidar_back/point_cloud/Data', pointcloud_callback, 10)
node.get_logger().info('Lidar PointCloud Subscriber is running...')
try:
rclpy.spin(node)
except KeyboardInterrupt:
pass
finally:
node.destroy_node()
rclpy.shutdown()
if __name__ == '__main__':
main()
```
