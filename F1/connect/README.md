**不包含私钥。** 专用隧道私钥在F1原地生成，禁止将F1的`keys/`取回本目录。不能用整目录覆盖同步删除F1密钥、日志或现场证据。修改先核对现场哈希、保留旧配置，再定向同步并验证；重启本服务会中断经隧道建立的SSH连接。
