# F1持久SSH连接配置

**2026-11-03 F1-09有线优先、Wi-Fi备用。** 日常局域网入口为当前有线DHCP地址`192.0.2.7`，Wi-Fi `192.0.2.3`保留备用；6000D继续经本机22009反向SSH进入，实际出站已走有线，不修改客户端回环地址。配置、地址稳定性及未验收的拔线／重启恢复见[F1-09接入记录](../docs/connect/F1-09.md#wired-router-20261103)。

2026-09-21 新增 **[3F-JIMU](../docs/connect/3F-JIMU.md)**（现场 `192.0.2.24`，端口 `22165`）：[独立配置](robots/3f-jimu/README.md) 已部署，免密登录、服务自启配置和进程自动恢复已验证。

本目录顶层配置对应旧 F1 D070（22022）；2026-09-18 新接入 F1（Wi-Fi `192.0.2.25`，22029）使用独立的 [配置目录](robots/f1-22029/README.md) 和 [接入记录](../docs/connect/f1-22029.md)。

操作、连接逻辑、排障和回退统一见[连接文档](../docs/connect/README.md)。

本目录保存6000D开发副本：`ssh_config`、核定主机公钥`known_hosts`、`systemd/f1-6000d-tunnel.service`和非秘密验证证据。部署目录为F1 `/home/user/Bruno/connect/`。

**不包含私钥。** 专用隧道私钥在F1原地生成，禁止将F1的`keys/`取回本目录。不能用整目录覆盖同步删除F1密钥、日志或现场证据。修改先核对现场哈希、保留旧配置，再定向同步并验证；重启本服务会中断经隧道建立的SSH连接。
