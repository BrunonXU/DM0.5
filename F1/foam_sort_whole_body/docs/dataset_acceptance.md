# 数据集发布验收：什么时候可以结束清洗

本文只定义清洗产物与正式数据reader的退出标准，不维护进度。当前范围和剩余工作见[当前方案](training_plan.md)，通用原则见[示教数据工作流](../../docs/dataset_workflow.md)，字段解释与执行映射见[动作接口合同](action_interface_contract.md)。

**2026-09-17用户明确：本轮demo以底盘与双臂时序一致为首要数据验收标准，精确距离replay不再是训练数据发布前置门槛。** 接受后补速度的尺度误差，不能接受抓放本应停车时标签仍持续移动。数据集发布、训练接线、真机执行分别验收；本次数据工作不承担IK优化、起姿控制和实机标定。现场就绪仍见[replay操作](replay_runbook.md)，此处不批准机器人动作。

### 当前demo的协同验收重点

- 以固定背景与三路原画面确定底盘移动/停稳，以夹爪和双臂命令/反馈辅助定位抓取接触、放置接触/松爪等关键操作。辅助信号不是实测底盘速度，不能只凭夹爪阈值强行改段。
- 已确认需要停车的抓放区间，底盘三维目标必须为零；检查驶离、停稳、操作、再次驶离的顺序与边界，没有跨操作段延续的错误速度标签。
- 手臂预伸、持物姿态调整可能与底盘移动同时发生；有画面支持的并行动作保留，不施加“手臂一动底盘就必须为零”的通用规则。
- 保留原录制时间轴，不能为凑0.5m/1.6m而单独延长底盘运动窗口，侵入抓放/静止区间。45.233秒重定时包仍仅作执行诊断，不能替换原28秒图像对应的训练时间轴。
- 幅值采用来源明确、单位/方向一致且平滑有限的弱目标；距离误差可以接受，不据此宣称恢复实测速度。未知保持隔离，不能用零伪装已确认停车。跨未知/复位的H50窗口无监督。
- 逐来源记录关键操作区间、底盘起止、重叠是否合理、证据及未决范围；完成选定训练范围的语义核验、reader、mask/split/统计与版本冻结后可发布demo数据，无需等待精确测距replay。

## 最终验收标准


下面是本轮训练集发布的验收要求，不是声称已经全部通过。
每次发布应保存来源、配置、切片、mask、分组、统计和回放报告，明确哪些录制/区间进入训练。

| 验收项 | 通过条件 | 不通过时处理 |
|---|---|---|
| 可追溯与完整 | 每个入选样本可回到原录制/时间；三路所选图像可解码；所有必需数值有限，维度/顺序/单位明确 | 重导出或隔离受影响窗口，保留原因；未知不填0冒充实测 |
| 同一时刻的观测 | 不取未来消息；使用当前版本配置的新鲜度门槛；曝光/时钟映射有证据，三路和关节事件没有未解释的持续错位 | 调整时钟映射并重新导出，无法解释则相应窗口暂不入选 |
| 正确的监督 | 已知错误底盘标签0条进入有效监督；每个入选循环有结果和人工干预标记，方向/起停阶段与画面相符 | 重标或排除错误监督，不能仅靠切视频修复速度 |
| 连续动作 | 不跨断档、人工复位或不连续循环；片段尾部未知动作无监督；未解释的跳变已逐项处理 | 拆段/修复时间或字段映射；不自动抹平所有动作变化 |
| 动作字段含义 | 来源关节动作19D与策略EEF动作23D的名称、符号、零点、尺度和FK前执行映射明确；没有未解释的超限/钳位 | 核对主从桥接与映射来源；IK求解、碰撞、起姿与实机控制单独验收，不阻塞本次已定义字段的数据清洗 |
| 分组与采样 | 同源子片段不跨训练/验证，重复录制不跨组；仅训练集统计；抓取/移动/放置/返回/等待比例有报告 | 按源分组，调整采样；合理停顿仍保留，常量维不能除0 |
| 训练与replay一致 | 用实际训练reader读取后能还原相同图像选择、状态、动作、mask与时间；归一化往返误差有记录且无意外改变 | 修复reader/编码；不能只验收另一套专用预览脚本 |

时间验收的具体解释：当前100 ms是数据新鲜度初筛，250 ms是header相对本流稳态偏移的异常筛选，
两者都不是“允许图像和动作错100/250 ms”。建议后续把经时钟校准后可测的观测对时残差以30 Hz一帧（约33 ms）为目标，
超过两帧的窗口复核；这是拟定复核尺度，未据此改变第一版mask，也不能在没有曝光时钟证据时宣布达标。

此外，命令先发、关节稍后才动是控制链路的真实延迟，不要求 `action(t) == state(t)`。
不能为了两条曲线重合把未来反馈移到当前观测，或把HAL关节状态当作lead动作替代。
后补底盘标签即使方向和时段核对通过，仍是弱监督；仅对其自身积分得出模板路程，不足以证明实测轨迹或实际可执行性。

按2026-09-16[正式recipe](training/dm05_eef_delta_recipe.md#2-输入19d包含当前底盘速度移除body5)，已复核重建速度也作为当前底盘状态估计进入state19；同一轨迹按未来索引用于动作监督。用户接受固定移动方式下这一近似，估计来源保留。这里的时间规则要求取当前`t`的估计、不把未来标签放入当前输入，不禁止离线复核后重建当前状态。

### 底盘重标的专项验收

2026-09-15根据[补标源码审查](../results/base_script_audit_20260915/report.md)补充。先验收小批修订，随后才扩大；人工确认记录是重标输入，不能把同一条拟合曲线既当标签又当真实性验证。页面操作和阶段定义见[底盘审核说明](data_cleaning/chassis_label_repair.md)。

| 层次 | 可检查的通过条件 | 证据与不通过处理 |
|---|---|---|
| 实际移动段与静止 | 每段记录实际起止和方向；后退、横移、前进只在有证据时填写，不强制每程三段或回到同一位置。段间停顿单独保留，多轮或同时两轴移动如实表示 | 完整三路原画面及固定背景审核记录。六个任务锚点不足以唯一确定全部移动段；缺失内部转折仍待审 |
| 启停定位 | 保存“最后静止帧—首个移动帧”等边界包络及原帧时间，标签边界落在人工核对的包络内。建议小批人工定位包络宽度不超过0.2秒，超过时回看原帧或标为未决 | 0.2秒是拟定的人工事件定位尺度，不是已达标结果，也不是允许曝光/控制时钟偏差；预览15fps约66.7ms一帧，不能宣称33ms定位精度 |
| 视觉与标签一致 | 有效监督内已确认的“零速而底盘移动”“移动时段错方向”“静止却持续给速度”冲突为0；已发现疑点全部有处理结论 | 重新筛查并逐项复核。筛查阴性不能自动通过；低像素位移不等于静止，未知或遮挡段暂不补确定速度。修订样本先完整人工看一遍 |
| 数值和时间合法 | 有效监督中的数值有限；未知候选可用NaN表达但必须被mask隔离，`0≤start<end≤录制有效末端`；没有意外倒序/重叠；坐标、单位明确。原点只换算一次，不用未来帧作为观测 | 原时间与派生索引核对；末端毫秒舍入须显式规范到可用时间，不可掩盖秒级漏段 |
| 弱速度尺度与时序 | 每段距离/幅值保留实测或先验来源，单位/方向、数值及平滑性合理；不为凑距离侵入静止/操作区间 | 0.5m/1.6m仍是历史路线依据，逐时刻速度为估计；2026-09-17用户接受demo距离偏差，实际测距不再是数据发布门槛。变更幅值须另存版本并一致更新当前速度估计、未来目标与统计，不能暗改其中一项 |
| 版本与有效性 | 记录源/脚本/参数/人工标记/新数组的SHA；新版本读取确实得到修订速度，旧原始数据不变；未知区间及跨界未来chunk不参与有效监督 | 不能以路径相同或消息数相同作为缓存有效条件。重新生成派生mask、chunk、统计及训练reader对照报告 |

**历史执行侧要求（2026-09-17起不作为本轮demo数据清洗/训练发布前置门槛）：** 2026-09-16补充执行约束验收：必须读取并绑定**当前控制器**速度、加速度、减速度参数；配置文件中的声明或平台阈值不自动等于当前生效值。对smoothstep另验`6×|d|/T²`，同时检查加速与减速限制。给定距离/时窗至少要满足起止静止的理论最短时间，并另外留出有证据的转向准备；理论可行不等于实机通过。逐腿比较实际派发命令积分、反馈积分、里程计及现场距离，禁止用正负相抵后的净位移或抓放成功代替路线验收。当前实证与可复算审计见[底盘运行核查](../results/base_controller_review_20260916/README.md)。

底盘专项通过只表示相应底盘监督可以进入下一步验收。双臂复位仍被隔离时，不恢复那里的19D监督；完整联合replay还须满足本文的接口、时序要求和[现场验收项目](replay_runbook.md#现场验收项目)。

## 正式reader离线验收

- 将源state21/action19与正式训练state19/action23放在同一时间轴，核对三路图像、各自来源时间与年龄、有效性mask、循环边界/人工干预区间；body5保留在来源与姿态检查，不进入模型。
- state19取双臂/夹爪当前反馈16维＋已复核底盘当前重建速度3维；当前底盘缺失则该观测无效，不能以0代填。底盘动作chunk沿同轨迹取`t..t+49`，保留首项`t`约定，未来预测误差另报`k≥1`。
- 状态与动作统计分别只从有效训练来源计算；输入底盘沿256档状态编码，动作底盘沿MeanStd。记录状态量化误差与裁剪比例、动作归一化往返误差，并核对在线`/move/State.speed`与训练估计的字段、坐标、单位和时序。
- 同时显示臂目标与反馈、夹爪开闭、底盘vx/vy/wz；可以积分显示一条**后补速度推算轨迹**，不标成实测路径。
- 支持逐帧定位关键事件，检查抓取、起步、释放、返回。原始流和导出样本能互相定位。
- 全量通过机器验收；人工重点看异常记录和修复记录，每批覆盖完整正常循环、最长/最短、较高速度以及右臂明显运动样本。
  抽查通过不能代替全部循环结果标注，报告必须列出覆盖范围。


独立核对原图/消息选择、动作字段、mask和归一化往返，保存同一版本的reader、统计和样本。已有数值回放器的dry-run不能替代正式训练reader。

## 发布与停止条件

- 首版在当前方案中明确入选来源和任务完成定义；只发布全部通过本合同的范围。
- 已知错误在有效监督中的数量为0；每个已发现疑点有修复、隔离或不纳入本版的结论。
- 一类问题关闭后，只有新证据影响该版本，或其输入/配置/算法发生变化，才重开对应检查。
- 额外样本量、已排来源事故溯源、模型效果优化进入后续版本；不要求全部历史数据均能救回才结束首版。
- 末端动作缺失若影响已承诺的完整任务，必须解决；不能通过改称“已清洗”绕过。

任务范围由[当前方案](training_plan.md)定义：用户可以明确将复位排除在本版学习与评测之外，此时不以恢复复位目标作为发布条件。仍须核实剩余任务是否完整；若mask同时去掉底盘返程，不能将该样本算作完整返程。动作mask是训练有效性，不表示发送零命令、自动保持或自动停车。

数据验收报告通过后冻结版本，交[replay操作](replay_runbook.md)安排现场验证。现场发现新的数据问题时，只回退受影响阶段并另存修订。
