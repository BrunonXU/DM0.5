# Whereweare 产品设计

2026-10-13 · Linear 方向桌面时间线 v0.5

已按用户授权实施[外置大脑方案](EXTERNAL_BRAIN_UIUX_PROPOSAL.md)，验证与实际边界见[STATUS](STATUS.md)。只做桌面网页。

- 左侧固定现在、项目库、回顾；首页保留 F1 积木主线与 DAgger、4242 支撑线。整体链路常驻，点击阶段看已具备能力、验收缺口、支撑项目与证据。
- 并行时间线共用真实日期；圆点成果、方形改动、菱形决定、三角验证缺口。同日多项展开，普通更新不伪造分支。
- 当前关口与下一步接在线上。旧记录保留真实日期，建议不伪造排期。核心节点18px，数据多时增加高度或进入详情，不截断验收边界。
- 自然滚页；横滑、Shift滚轮、空白拖动浏览历史；范围按钮、回到现在、详情返回保持位置。新版本先提示载入，避免替换正在阅读的事实。
- 回顾入口只读，选周期后明确生成。报告按时区、周期、事实版本和决定版本缓存，独立保存，不能覆盖首页。
- 文档按来源哈希及实际读取行记录覆盖。暂停/完成决定独立存储；更正事件保留历史。模型只有已登记证据，默认无自动调用。
- 自动更新可在更新状态开启：当前项目、稳定两分钟、默认每天最多8次；失败同一变更不反复重试。强度high。
