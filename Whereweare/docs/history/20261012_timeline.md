# Projects Hub 当前状态

更新：2026-10-12（上海时间）。

## 当前方向

首页改为**从左向右展开的时间树**，项目主线用不同颜色区分，节点可继续分叉。主页保留短标题与状态，详情按需打开，移除专注计时与原六视图仪表盘。

旧版验证结果已保留到[历史验收记录](20261012_dashboard.md)，不作为新版验收结论。

## 已完成

- 全屏 SVG 横向时间树：四条交付主线固定颜色，共享工具合并为可展开灰枝；可拖动、缩放、筛选和折叠。
- 首页只有短标题与节点；点击打开详情或来源。手动节点可创建多个子分支、编辑状态并持久保存。
- 显式日期映射到时间刻度，未指定日期的节点单列在「待排期」区域。共同根只表示工作区归属。
- 时间树手动节点保存到独立的 `timeline_nodes` 表，旧任务与时间记录保留。
- `POST /api/timeline/nodes` 创建节点，`PATCH /api/timeline/nodes/{id}` 修改标题、状态、日期、备注与父节点；所属项目不可更改。
- `GET /api/state` 与 `GET /api/briefing` 均返回 `timeline_nodes`，便于页面和后续 Agent 读取。
- 分叉仅允许关联同项目手动节点，可有多个子节点；禁止循环。父节点为空表示项目主线上的独立节点。
- 日期只接受明确录入的 `YYYY-MM-DD` 或 `null`，未排期不按文件时间补造。祖先与后代的已定日期不得倒序，跨过未排期节点也会检查。
- 原有文档指纹扫描、来源阅读与有界差异保留；自动摘录仍采用规则，无后台 AI 调用。
