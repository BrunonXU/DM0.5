# 数据目录

| 目录 | 性质 | 是否可重新生成 |
|---|---|---|
| `raw_samples/` | 私有原始episode样本，不进入公开仓库 | 应从内部存储恢复 |
| `processed/smoke/` | OpenDM JSONL和无重编码MP4 smoke | 可以由转换工具重新生成 |
| `audits/` | 归档索引、H5审计和动态诊断证据 | 建议保留 |
| `manifests/` | 后续冻结的train/validation划分 | 正式生成后必须保留 |

原始数据来自内部共享存储，公开仓库不记录服务器地址或访问凭据。

公开仓库只保留 `processed/smoke/` 中的单episode格式示例；原始H5/H.265和
全量归档索引存放在项目外的私有数据目录。

不直接从SMB训练；大归档先复制到训练服务器本地NVMe。转换产物不写回共享盘。
DM0.5模型权重不放在本目录。
