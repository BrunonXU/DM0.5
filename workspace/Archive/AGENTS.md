# Archive 协作入口

这里保存从 Projects 移出的历史项目，迁移不代表重新启动开发或服务。DM0.5 与 g2_robot 仍配套保存；Whereweare 已按用户要求搁置，恢复必须由用户明确提出。

开始工作前遵循 [Projects 协作规则](../../AGENTS.md) 和 [项目规则与习惯](../../PROJECT_RULES_AND_PREFERENCES.md)，再读取所属项目的 AGENTS。目录、Git 归属与迁移证据见 [Archive 说明](README.md)。

- Archive 是同仓库的独立 linked worktree，当前 detached HEAD；未提交修改在此工作树维护，不自动提交或推送。
- `.git` 依赖 Projects 的 Git 管理目录，不删除、不重新初始化，也不运行 worktree remove。改变布局前先读 README 的稀疏工作区说明。
- 只做迁移导航与路径适配，不批量改写历史证据或实验结论。历史命令在恢复前核对路径与实际进程身份。
- Whereweare 保持 disabled/inactive，不主动扫描、发布、审阅或恢复服务；恢复前还需核对跨目录来源及 tracking 存储。
- DM0.5 与 G2 的现场动作权限以所属项目规则和用户当前授权为准，归档不增加任何训练或真机操作授权。
