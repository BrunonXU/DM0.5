# 文档目录

本目录只保留G2现场离线也必须能读到的操作、API和部署快照。跨服务器与真机的权威知识库为 [`../../DM0.5/docs/README.md`](../../DM0.5/docs/README.md)，写入规则见其中 `AGENTS.md`。

- `00_G2_OPERATOR_GUIDE.md`：现场唯一优先操作入口。
- `12_G2_CLIENT_DM05_RUNTIME.md`：历史/现场客户端实现快照；目标架构以DM0.5 docs为准。
- `G2_ACTION_SMOOTHING_PLAN.md`：动作平滑原始设计与实验来源，后续结果迁到DM0.5 experiments。
- `G2_ROBOT_STRUCTURE.md`：当前目录结构。
- `G2_TROUBLESHOOTING.md`：尚未全部迁移的一手故障记录；分类索引在DM0.5 incidents。
- `GDK_2.6.3_RELEVANT_API.md`：本项目涉及的官方GDK接口摘要。
- `Bruno.md`：现场临时状态；跨系统权威状态在DM0.5 `CURRENT_STATUS.md`。

操作步骤发生变化时先更新操作指南和结构说明；架构、原理、实验或事故写入DM0.5分类目录，并从本地页面链接。
