# 接口说明

工作台 HTTP 接口服务于本机网页与受控集成。通常直接使用浏览器即可；本页供需要读取状态或对接现有工具的部署人员查阅。

端口为 4242，地址为 `http://机器人IP:4242`。GET 读取状态不会启动动作、遥操或录制；能力是否可用以本机配置和实时状态为准。

## 常用只读入口

| GET 路由 | 内容 |
| --- | --- |
| `/api/robot` | 机器身份、显示信息、关节分组与能力 |
| `/api/state` | 实时反馈、控制权、动作与系统状态 |
| `/api/system` | 运行配置与系统能力 |
| `/api/storage` | 存储与资源快照 |
| `/api/cameras/head.jpg` | 头部最新 JPEG |
| `/api/cameras/left.jpg` | 左腕最新 JPEG |
| `/api/cameras/right.jpg` | 右腕最新 JPEG |
| `/api/data` | 已接入的数据目录与条目 |
| `/api/recording/state` | 独立录制状态 |
| `/api/teleop/state` | 网页管理的遥操会话状态 |
| `/api/hil/routes` | 已配置的手柄路线与启动指引 |
| `/api/hil/state` | 外部手柄运行端的可核对状态 |

JSON 响应通常包含 `ok`，错误包含 `error`。相机没有新鲜画面时可返回 503；不存在的接口返回 404，状态冲突返回 409，Host 或同源检查失败返回 403。未知反馈不填零，时间新鲜度需与值一起判断。

## 写入与动作

当前版本无需密码；浏览器 Cookie 用于隔离会话与控制租约。写请求仍需符合 Host、同源与接口合同，网页使用 `Origin`、`X-F1-Request: 1` 和 JSON 请求体。

机器人动作需要有效控制租约，并经过本机能力、反馈、限位与来源检查。请求成功仅表示进入动作生命周期，不代表实物到位；状态、停止和完成结果继续通过对应接口跟踪。不要用发送动作作为接口连通性测试。

详细字段以随包 `server.py`、对应服务模块及 `web/app.js` 为准。先完成本机模块配置再接入写接口，不通过修改模板启用标记绕过本机适配。
