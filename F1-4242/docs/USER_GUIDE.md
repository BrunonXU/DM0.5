# F1-infra 使用说明

打开平台先显示一次红字操作须知，点击“进入工作台”后操作无需密码，也不再逐次确认。进入或刷新页面本身不启动动作；修改目标、载入预设也不会自动执行。

入口为 **http://机器人IP:4242/**，以本机 profile 和启用能力为准。新机先按 [部署说明](SHARING.md) 配置；下文 F1-09 预设、历史录制和现场限制只是已有部署的实例。

工作台保留“总览、调试与姿态、Pico 遥操、HIL、数据”五个入口。总览与系统配置已合并：Start All 位于总览，身份、服务与版本从“系统详情”打开，顶部“操作会话”查看控制权并释放。线上版本见 [STATUS](STATUS.md)。

总览的“一键启动 Start All”先核对本机状态，点击后直接启动；现场 EC 主站与手柄条件需由操作者预先核对。请求受理、脚本完成和设备反馈分开显示；基础节点已存在时不会重复启动。打开“启动详情”可查看完整结果、范围与现场命令。旧 `#system` 链接会打开总览中的系统详情。

页脚“实时反馈 · F1 / 4242”旁的 **Why&How ↗** 在新标签页打开[交互讲解与文档阅读站](http://192.0.2.1:4243/)，用于阅读训练、数据处理等说明；浏览器需能访问6000D内网地址。该入口的发布状态见 [STATUS](STATUS.md)。

## 先看现场

总览、调姿、Pico 与 HIL 提供头部、左腕、右腕实时相机；数据详情只显示历史录制画面。页面状态和实时 JPEG 默认每 750ms 更新一次（约 1.3 次/秒），不等于相机采集帧率；目录/系统约 10 秒刷新，前端资源版本每 2 秒检查。实时图像以各自收到帧的时间判断，缺帧时显示缺帧，不把历史图像当实时图像。设备状态分开呈现连接、关节反馈与相机反馈。

## 调整与执行

1. 在“调姿”中编辑双臂、夹爪、身体或头部；也可点击顶部预设直接载入。
2. 顶部显示这次所有待执行部位与检查结果。载入全身复位就包含双臂、身体和头部，不再另选执行部位。
3. 点击“执行”。按需取得本浏览器控制权后直接提交，不输入密码、不弹出二次确认。整套检查不通过时不会部分执行。
4. 顶部显示整项进度和到位结果。已在误差内无需动作；任一部位未到位不能报整体完成。
5. “停止动作”停止本次任务，“退出操控”另释放控制权；“重置编辑”按当前实测清空所有待执行编辑。

默认显示双臂与夹爪，在同一编辑区切换身体、头部；切换保留草稿，部位入口显示待执行修改数。双臂左右成对，实测与目标并列，模型与相机位于右侧。身体升降保持模型俯仰，厘米位移仍待实测标定；编辑弯腰/高级关节会替代升降目标。保持固定速度；长动作由后台连续执行，显示整项预计用时，无需用户分段。底盘在“移动”中按住点动。

关节编辑区以“关节 / 实际”和“目标”标识两类读数：角度显示一位小数，夹爪百分比显示整数，接近零的负数不显示为 `-0.0`。编辑时保留输入，离开输入框后统一显示位数；预设和手动输入的完整精度仍用于计划与执行，显示取整不会改写控制目标。此项开发与部署状态见 [STATUS](STATUS.md)。

预设右上角“新增”可保存22轴实测或导入JSON。每项“···”可导出/删除。F1-09 已有配置中，全身默认来自原生pose_2，双臂等于LXL XY；不等于每个编码器都为0，也不包含夹爪和底盘位置。删除默认项后不自动重建。完整交互及限制见 [统一姿态任务](POSE_TASK.md)。

## 3D 模型

鼠标旋转、缩放观察 F1 模型。实测模型与目标预览分开标识；关节名称、角度转换和未知项见[模型说明](MODEL.md)。机器人模型不是现场环境地图，也不能据此证明机械零位已现场标定。

## 数据文件夹、三路回放和备注

数据页采用中性灰白设计，按LXL/DAgger、人工示教/策略HIL浏览；支持子目录／全部录制搜索和日期筛选，每页固定8条。录制列表的“备注”可直接点击编辑，长内容悬停查看，空白显示“＋添加备注”；搜索也匹配已保存备注。录制列表使用完整宽度，容量和版本目录保留在下方。训练导出单列，回到目录恢复位置，当前交互见 [数据说明](DATA.md)。

点击录制进入独立详情，返回文件夹保留搜索、目录和页码。未保存备注草稿按录制和来源隔离，保存在当前浏览器标签的会话中，刷新可恢复；取消不提交服务器。三路画面与时间轴为主区域：

1. 有原图接口时默认显示保存的三路原图，可播放、拖动时间轴、按原始像素放大或下载；原图连续浏览最高5fps，与采集帧率独立。
2. 有派生视频时展开“视频回放与曲线 · 压缩副本”，共用进度条支持±5秒、0.25–2倍速及state/action曲线。
3. 右侧默认“保存备注”，不要求逐条审核；原审核操作位于底部“审核记录（可选）”。文件明细、存储路径与消息主题也默认折叠，文件明细展开后限高滚动。
4. 人工示教右上角“实机 Replay”进入独立控制区，起点状态、时长、开始与停止集中显示；区间/诊断默认折叠。点击即提交运动，不再弹窗确认，详见 [REPLAY](REPLAY.md)。

具体录制目录可以“选择”，全选只作用于当前筛选页，可跨页保留选择；界面显示总选中数，点击删除即提交所选条目；源签名与并发检查仍执行。上级来源不递归批量删除。
旧 MCAP 的预览以 bag/log 时间生成 10fps 审阅缓存，超过 250ms 没有新记录的画面显示缺帧；曲线未知值不补零。共同时间轴不代表历史三路源图像严格同时曝光，也不是训练对齐验收。

备注和审核另存到本工作台 runtime，绑定来源签名；保存备注不改变原审核结论。发生来源变化或其他窗口更新时先核对，页面保留草稿，不自动覆盖。审核通过仅代表操作者结论，不自动上传、不自动成为训练可用数据。

## 独立 LeRobot 录制

复用 meaxiao 录制/审核流程，适配为 F1-09 上肢 16D、10fps。LXL 的主分支和录制入口不变，新数据保存在 `/home/user/Bruno/F1-infra/runtime/recordings/upper16_v1/`。

1. 在机器人旁按[Pico 上肢说明](../integrations/pico_upper/README.md)准备独立遥操。可从 Pico 页点击启动上肢版，或从 `/home/user/Bruno/F1-infra/current/integrations/pico_upper` 目录运行 `./start.sh`。
2. 在 Pico 页的“LeRobot · 独立上肢录制”直接操作即可，不必取得网页动作控制权；Pico 可以继续持有控制锁。保存后的文件和历史回放在数据页查看。
3. 点击“启动独立录制服务”，只准备订阅。查看就绪条件：三路图像、关节反馈、已验证 Pico 会话及双夹爪实际命令都需满足要求。
4. 就绪后明确点击“开始录制”；完成后点击“结束并审核”，查看这次采集的三路回放，再点击“保存这条录制”。
5. 通过完整性检查的片段保存为 LeRobot；来源变化、缺帧或覆盖不足的观测保留为 recovery，不混入正式训练片段。

切换页面不会停止录制；页面顶部显示进行中/待保存状态。状态失联时先恢复连接，避免重复准备。保存为本地操作，不启动传输任务。详细字段和约束见[数采合同](RECORDING.md)。

## Pico

Pico 使用“运行现场、连接与启动、独立录制、操作对照”四个横向标签。两套版本的网页启停、现场脚本与日志保留；顶部持续提供当前会话的停止入口。切换标签保留录制和待保存片段，隐藏的相机画面暂停请求，返回后恢复。网页点击启动后自动预检，通过后继续启动，不会随页面打开或开机自动启动。详见 [Pico 启停](PICO.md)。

## 常见问题

| 情况 | 处理 |
|---|---|
| 网页能开但没有关节反馈 | 检查基础驱动和 ROS 状态，SSH/HTTP 在线不代表电机节点在线 |
| 相机显示缺帧 | 分别检查对应相机，不用另一相机健康状态代替 |
| 无法取得控制权 | 检查其他浏览器和 Pico 是否占用；不用停止其他进程来强抢 |
| 目标已输入却无法执行 | 检查本组能力、实测新鲜度、关节行程和固定速度预算，页面会显示具体原因 |
| 修改前端没刷新 | 确认浏览器访问的部署版本和 `--web-root`；若启用热更新，再检查自己的同步服务 |
| 4242 打不开 | 局域网用 F1 地址；远程使用 VS Code 转发后的地址，并检查 SSH 隧道服务 |

开发者请读[接口文档](API.md)与[架构说明](ARCHITECTURE.md)。

## 网页遥操启停

Pico 页现提供 LXL 和 meaxiao 上肢版：释放姿态控制权 → 点击启动 → 预检通过后继续启动。停止按钮仅结束该网页会话；不会结束原终端启动的程序。刷新/关闭页面不停止遥操，开机不自动启动遥操。LXL 保留初始位动作与腰部按键；当前精细双臂操作优先使用上肢版。详见 [两套脚本、按键和数采差异](PICO.md)。


## 基础节点与界面空间

系统配置页“启动基础服务”点击后直接调用已核验原 start_all.sh；已启动或部分运行会阻止重复启动。EC-Master 不包含在该脚本中，现场启动命令见卡片。原 Pico、独立录制和回放入口各自保留，不随基础启动自动运行。

左侧右上角的收起图标释放宽度；姿态页左右臂同一行对应同一关节序号，右侧模型固定且可进一步“放大模型”。穿地目标变红并说明原因；系统配置保留服务状态与版本信息。

### 复位和执行异常

选择“全身复位”后点击一次执行即可提交全部22轴目标。内部检查和长动作调度由后台处理，页面没有逐段操作。点击停止取消整项任务，恢复连接不会继续上次动作。

F1-09原有头部异常角度已于2026-09-28完成回程。正常使用时，选择右侧姿态、点击执行，后台完成整套目标，无需拆分步骤。预设与手动调整遵守同一驱动范围；预设不代表任意路径都防碰撞。若再次遇到已支持的轻微头部越界，页面会显示回程状态，点击执行包含该回程，随后由后台衔接最终姿态。具体边界见 [姿态任务](POSE_TASK.md)。


### 备注如何保存和迁移

点击“保存备注”后，内容写入该条录制目录的`f1-annotations.json`；关闭浏览器或清缓存不影响已保存内容。复制、归档或迁移时带上整个录制目录即可。尚未点击保存的输入只是本次浏览会话草稿。

移到新路径时备注文字会恢复，原审核作为历史保留，当前状态重新待审核。文件写入失败会明确报错，不会只存浏览器却显示已保存；既有原始采集文件保持不变。旧工作台`runtime/data_reviews`文件保留作迁移前备份。

### 手动整理数据版本

在数据页点击「新建文件夹」命名版本；把录制或自建文件夹拖入左侧文件夹或右侧版本目录。支持跨页选择后「移至…」，也可进入文件夹后重命名。所有文件夹层级保留黄色文件夹，存储与版本目录在右侧显示；只有进入最末级录制列表后才铺满内容区、把侧栏移到下方。存储单独列出真机rollout，不与DAgger重复计数。左侧导航保持与其他页面一致。分类永久保存在平台，原始文件位置、审核与 Replay 关联保持不变。
