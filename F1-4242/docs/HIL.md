# HIL 页面

新版提供三路线指引、可视手柄教学、彩色模式、三图预览和介入视频接口；遥操旧入口仍保留已验收v15，新路线候选需现场测试。部署事实和候选验收边界见 [STATUS](STATUS.md)。

开发版以紧凑状态栏呈现控制阶段、演练/实机、选臂/RB、输入/三图/记录健康，随后是三路实时视野及当前录制操作。启动指引、手柄教学、介入记录与诊断默认折叠。手机将头部主视角与双腕缩略画面分层，减少纵向滚动。Y复位阶段与停止原因保留，展开原因不会被状态轮询重新收起。蓝色人工、紫色策略、黄色等待、红色保护、灰色未知；绿色仅表示健康。文字和图标与颜色一起显示。普通软限位仍属人工接管，标记“方向受限”；松RB显示人工保持。

HIL预览目标每路10fps，其他页面约1.33fps；原始DAgger采集保持30Hz。每路一个在途请求，隐藏/离屏/收起/切页主动取消。接收年龄超过500ms提示延迟，2秒失鲜遮罩。同一个页面的组件不会叠加；多个可见窗口会叠加传输。关闭页面不关闭相机，也不停止机器人控制或采集。

10fps是已做有限验证的默认折中值，不是已证明的最优帧率。历史约10分钟开/关预览对照中观测均约29.94Hz、写盘无错误，但HIL进程CPU及观测间隔分布存在变化，不能宣称零开销。另一次短测中10fps目标实际下载约9.2–9.5fps、图片有效载荷28.65Mbps；30fps目标只下载到15.6–16.0fps、48.51Mbps，不能算30fps实效验收。20fps尚未测量；Windows实际链路、浏览器解码及操作中ACK的同条件10/20/30fps对照待做。实时JPEG预览与DATA的30fps压缩视频回放是不同链路。

## 三条操作路线

入口只有自由接入、人工示教、策略 HIL。点击只切换指引，不保存配置、不启动任何进程。每条路线提供 F1 运行端、Windows 隧道、Windows sender 三个命令及由接收端状态确认的进度。输入未收到时，页面不能仅凭本地 SSH 已连接就显示链路正常。

三条路线共用可点击 F710 二维图。选键高亮并在右侧播放 F1 原 URDF/网格的右臂教学动画；动画使用离线 IK 示例，非实时状态或实机命令，夹爪几何仅为示意。模型按首次点击载入，资源复用现有模型缓存；离屏、隐藏、收起、切页停止动画。手柄布局参考[罗技官方图解](https://www.logitech.com/assets/48300/f710-wireless-gamepad-quick-start-guide.pdf)。

配置只在后端维护：`runtime/hil.json` 保存运行目录/SSH地址；`runtime/hil-routes.json` 按 play、demonstration、policy 提供 launcher、session_config、candidate。每个 session JSON 使用 `f1_hil_session_v1` 合同，分别指定 teleop_play、demonstration、policy_hil。模型地址、任务、30Hz/H合同、自动视频不再出现在前端表单。未绑定模型时策略路线显示“模型未绑定”，禁用运行命令复制；运行端同样拒绝无端点启动策略。

部署端配置 `F1_HIL_ROUTE_DIR` 与 `F1_HIL_ROUTE_EXECUTION`，显式现场包装器调用 `scripts/67_f1_route.sh play|demonstration|policy`。脚本默认 shadow；本站经软件验证的候选包装器选择 powered，仍需现场执行命令、Enter、手柄 START，网页没有动作按钮。自由接入不保存训练图像、不生成视频且禁止训练导出；保留诊断日志。人工示教保存30Hz原始数据；策略 HIL 保存策略和纠正记录。选页不改变正在运行的会话。

旧 `hil-session.json` 及配置/探活/试推理 API 保留给后端兼容工具，不参与新路线选择；后端维护新模型时应针对 policy.json 进行合同检查。历史 v15 主启动入口保留，不读取新路线用途。

复位局部停止但HIL仍存活时，页面显示“Y复位已停止”和原始原因。Y会清空选臂，提示松Y/RB、重新选右臂后释放十字键，再按RB接管。START可取消Home并保存示教当前条，仍需松RB并等待真实夹爪动作完成。

## 状态和API

| 接口 | 作用 |
|---|---|
| GET /api/hil/routes | 后端已安装路线、三个启动命令和模型绑定就绪提示；只读 |
| GET /api/hil/state | 当前进程绑定的状态，structured 2秒过期；兼容v15日志8秒过期 |
| GET/POST /api/hil/config | 下一会话用途、任务、模型和自动视频 |
| POST /api/hil/policy/check | 健康接口，无图片 |
| POST /api/hil/policy/probe | 新三图/state单次试推理，无动作 |
| GET /api/hil/interventions | 最多100个最近派生任务 |
| GET /api/hil/video/{job}/{clip}.mp4 | 本地回放，支持Range |
| POST /api/hil/media/retry, review | 失败重试/单片段审阅，不批准训练 |
| POST /api/hil/media/claim, source, progress, upload, publish, finish | 认证worker传输协议，单租约、源与回传校验 |

原相机URL不变，增加 `X-F1-Frame-Id`、`X-F1-Frame-Age-Ms` 响应头。读缓存不递增帧身份。没有额外ROS订阅或图像编码。

structured快照为DAgger runtime/status.json，绑定PID、进程start_ticks、会话ID和时间；超过2秒或进程不符即未知。v15只读取128KiB控制台尾部，不能补造ACK、实测跟随或模型状态。详细指标和版本留在折叠诊断；相机图像是现场视野，录制帧数是已写盘证据，两者含义不同。

## 介入视频

服务器worker从完整提交会话读取片段所需图像，经三图编码后回传本机videos；本机持久任务在video-jobs。没有服务器时显示等待配置/等待服务器；控制和数采不依赖它。活动HIL/数采暂停大文件传输，服务器编码可继续。视频H.264、30fps仅为展示，保留原始图像索引与时间。

任务状态和片段审核分开。视频可播放不等于采纳，采纳不等于LeRobot训练就绪。原始数采不被修改，异常partial不自动修复/导出。后台每10秒检查完整会话manifest，活动期间不扫描；HTTP状态不读取逐帧journal。

本候选的软件/浏览器/合成视频测试与实机性能验收分开记录。已完成预览开关各10分钟的真实反馈shadow对照，约29.94Hz、写盘错误/丢弃为0；Windows手柄实机操作与ACK验收仍待现场进行。

## 急停与本次执行侧故障

2026-10-10现场会话中，接收端收到START/RB及非零摇杆，ROS发布及厂商motor_ctl接收日志均存在；14关节反馈全程完全不变，Home反馈超时。操作者随后确认误按实体急停。当前证据把问题定位在厂商驱动/控制器/硬件执行侧，不能把publisher成功或ROS新时间戳当作真实硬件跟随。

保持sender与HIL停止，按原厂现场流程解除急停、清故障与恢复使能。基础启动阻止重复节点，不是驱动复位按钮。若仍无硬件反馈更新，应检查/重新初始化原厂驱动连接；本轮不远程复位急停、不自动重启驱动或发送试探动作。

教学动画幅度已扩大；RT示意夹爪移到末端法兰外沿本地−Y安装，带掌体、两指及特写。它不是夹爪CAD或物理标定。仅修改教学表现，未提高实机遥操速度、步长或限位。

人工示教保留：用于无策略专家采集（30Hz），不同于不写训练图片的自由接入和策略纠正HIL。首页是否改为两入口尚待产品选择，不删除既有记录和导出能力。

## 结束与查看录制

人工示教运行端 v20 使用 START 分条：START 开始；释放 RB、等待夹爪/Home 完成后再按 START 结束并保存。保存完成后可开始下一条，三端进程无需重启。空闲期间不写训练三图与逐帧日志。网页显示未录制、正在录制、正在保存；「结束运行端」保存当前条并退出。每条保存在本机 Bruno/data/hil_data/demonstration，DATA按文件夹查看。断线收尾并保持，不自动恢复；保存期间的 START 不延迟执行。策略 HIL 的 START 仍是接管/交还。

以下为旧 v18 / 策略 HIL 的整进程结束行为：

HIL流程中点击「结束并保存」（自由接入显示「结束会话」），登录沿用工作台控制码，不取得网页运动控制权。此操作结束整个当前HIL会话并停止遥操；F1原控制进程关闭输出、排空写盘队列并提交原始数据。按钮与run_id、PID及进程启动身份绑定，旧页面不能停止新会话。网页显示「正在整理」后须等待「已保存」，才跳到DATA对应记录。旧运行端不支持时，在F1运行终端按一次Ctrl+C并等待退出；START仍只负责接管/交还。关闭sender或网页不等于结束录制。

后端F1_DAGGER_DATA_ROOT设为独立数据根，机器人安装使用/home/user/lxl/dagger_data；demonstration与policy_hil分目录。诊断和状态仍保留原runtime；自由接入不保存训练图像。旧runtime/raw保持只读并兼容索引，无需搬动。

DATA新增F710人工示教及策略HIL分组，直接按时间读取原始三图，播放预览最高5fps（不改变30Hz采集），暂停后可拖动定位；隐藏、离屏与切页取消请求。帧接口校验索引及单帧哈希，网页不执行全量训练审计。正常提交、内容审核、训练就绪分别管理；Home和异常边界仍需导出筛选。
