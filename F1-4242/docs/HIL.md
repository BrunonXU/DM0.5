# HIL 页面

**策略HIL当前只开放B1250；父DAgger1K的启动选择已暂停，不在运行中热换模型。** 人工示教和策略HIL操作保持统一：START开新条／策略中接管，人工阶段START不交还、不结束，也不是暂停恢复键。收尾由操作者决定；松RB、等夹爪操作完成后按↑保存，不要求先回位或等待固定时长。

2026-10-23取消保存前的回位／两秒门槛，Y保留为可选快捷回位：先由操作者避开桶，再松RB按Y直接回积木demo-V1；正在回位时须等动作结束后再按↑，无需额外计时。人工候选碰撞或手柄链路暂停仍保留同一条录制，按“松RB、回中 → 输入确认 → 重新RB”恢复；硬故障按保护中断封存。实现、部署和真实动作验收分别见[状态](STATUS.md)。

本页提供三路线指引、可视手柄教学、三图预览和介入视频说明；下文旧入口描述保留其适用版本。2026-10-26模型切换的配置、身份与软件检查已完成，B1250真实HIL接管仍待现场；部署事实见[STATUS](STATUS.md)。

自由接入和人工示教已按确认的横向候选实现：顶部「运行现场 / 连接与启动 / 手柄教学 / 诊断」四个入口，结束运行端按钮常驻。运行现场横排状态、已写盘帧数和当前操作，随后三路相机并列与保存记录入口；未运行时默认打开连接页。三步命令横向切换，支持全部展开、右上角复制；命令仍来自后端，不由前端硬编码。首页保留三个流程，策略 HIL 详情本轮沿用原布局。

教学复用现有 14 个手柄按键和真实 URDF 动画，支持 START、夹爪、复位快捷入口。诊断按连接/记录、会话/版本、观测指标、消息、原始原因和完整摘要分组；介入视频的播放、重试和审核入口仍保留在诊断页。保存详情衔接原数据页的原图回看、审核和 Replay。非现场页仍显示运行状态和异常；输入暂停、Y 复位阶段/停止原因、软限位、写盘失败、失鲜、会话冲突与收尾结果均保留。切换功能页不重建运行会话，隐藏相机和教学时暂停预览/动画。

结束操作先显示确认，再复用工作台登录；确认时与登录后均检查当前会话身份，失鲜、流程不匹配或重复提交时禁止发送。实际运行模式、帧数和保存 ID 来自现有接口，没有补造录制计时或前端启动按钮。三个桌面尺寸为 1920×1080、1440×900、1280×800；本地实现与发布状态见 [STATUS](STATUS.md)。

HIL预览目标每路10fps，其他页面约1.33fps；原始DAgger采集保持30Hz。每路一个在途请求，隐藏/离屏/收起/切页主动取消。接收年龄超过500ms提示延迟，2秒失鲜遮罩。同一个页面的组件不会叠加；多个可见窗口会叠加传输。关闭页面不关闭相机，也不停止机器人控制或采集。

10fps是已做有限验证的默认折中值，不是已证明的最优帧率。历史约10分钟开/关预览对照中观测均约29.94Hz、写盘无错误，但HIL进程CPU及观测间隔分布存在变化，不能宣称零开销。另一次短测中10fps目标实际下载约9.2–9.5fps、图片有效载荷28.65Mbps；30fps目标只下载到15.6–16.0fps、48.51Mbps，不能算30fps实效验收。20fps尚未测量；Windows实际链路、浏览器解码及操作中ACK的同条件10/20/30fps对照待做。实时JPEG预览与DATA的30fps压缩视频回放是不同链路。

本地精修中，运行会话名称与操作依据实际身份，选择其他路线只改变指南；状态有效期沿用服务端值。结束请求即时锁定重复提交，保存后原地显示“查看这条”，链接经目录身份验证，连续采集不自动跳页。见 [精修交付](UIUX_UPGRADE.md)。

## 策略模型选择与会话边界

当前装配只登记B1250（默认，`--model stageb1250`），省略参数也使用B。按2026-10-26后续决定，父DAgger1K、A1250和旧Full的服务、转发及活动登记已停止，旧别名不再接受；权重、日志和旧装配保留。此前B／父1K双模型登记已完成部署与检查，现作为历史事实保留在[状态](STATUS.md)，不代表父1K此刻可选。

通用`--model`选择机制仍保留，参数在启动F1运行端时绑定已安装模型。以后恢复其他checkpoint，需要先登记、部署并校验对应模型身份与输入合同；换模型时保存当前录制并退出运行端，再启动新会话。活动会话的模型身份、RTC动作前缀和录制来源不能在中途换绑。

完整三端命令、现场Enter／START流程与日志目录统一在[任务STARTUP](../../tasks/F1_ComplexyToys/inference/STARTUP.md#rtc-hilfull1k真实手柄接管)，也可打开[Why&How现场教程](http://192.0.2.1:4243/?doc=f1-startup)。工作台不通过页面刷新、路线选择或模型状态查询启动动作。

模型连接由任务装配catalog生成，启动时同时校验真实模型身份、版本和输入合同；不能只改一个端口绕过绑定。工作台的`runtime/hil-routes.json`顶层`installed_policy_models`保存已安装模型的`model_id`、绝对`runtime`及`session_config`，当前该表只保留B1250，policy路线与B的runtime不变。后端将已登记runtime加入状态／收尾允许列表并动态读取配置；未知路径、无效登记和不匹配的会话收尾仍拒绝。旧配置没有该字段时保持原路线白名单行为。模型登记与端口的完整约定见[任务推理recipe](../../tasks/F1_ComplexyToys/INFERENCE_RECIPE.md#hil-model-selection)。

## 三条操作路线

命令复制兼容 HTTPS/本机与局域网 HTTP 页面：优先使用 Clipboard API，无法使用时尝试原生复制后备路径；成功才提示“已复制”。若浏览器同时阻止两种方式，明确提示并选中原命令供手动复制。此修复的发布状态见 [STATUS](STATUS.md)。

入口只有自由接入、人工示教、策略 HIL。点击只切换指引，不保存配置、不启动任何进程。每条路线提供 F1 运行端、Windows 隧道、Windows sender 三个命令及由接收端状态确认的进度。输入未收到时，页面不能仅凭本地 SSH 已连接就显示链路正常。

三条路线共用可点击 F710 二维图。选键高亮并在右侧播放 F1 原 URDF/网格的右臂教学动画；动画使用离线 IK 示例，非实时状态或实机命令，夹爪几何仅为示意。模型按首次点击载入，资源复用现有模型缓存；离屏、隐藏、收起、切页停止动画。手柄布局参考[罗技官方图解](https://www.logitech.com/assets/48300/f710-wireless-gamepad-quick-start-guide.pdf)。

F1-09的日常SSH目标优先`user@192.0.2.7`，`user@192.0.2.3`仅为Wi-Fi备用。网页复制命令读取`runtime/hil.json`的`ssh_host`；Windows已安装包仍应核对自身默认地址或显式传入`--robot-host`。主备网络切换需要重新建立会话，不绕过真实START或输入恢复保护。

配置只在后端维护：`runtime/hil.json` 保存运行目录/SSH地址；`runtime/hil-routes.json` 按 play、demonstration、policy 提供 launcher、session_config、candidate。每个 session JSON 使用 `f1_hil_session_v1` 合同，分别指定 teleop_play、demonstration、policy_hil。模型地址、任务、30Hz/H合同、自动视频不再出现在前端表单。未绑定模型时策略路线显示“模型未绑定”，禁用运行命令复制；运行端同样拒绝无端点启动策略。

部署端配置 `F1_HIL_ROUTE_DIR` 与 `F1_HIL_ROUTE_EXECUTION`，显式现场包装器调用 `scripts/67_f1_route.sh play|demonstration|policy`。脚本默认 shadow；本站经软件验证的候选包装器选择 powered，仍需现场执行命令、Enter、手柄 START，网页没有动作按钮。自由接入不保存训练图像、不生成视频且禁止训练导出；保留诊断日志。人工示教保存30Hz原始数据；策略 HIL 保存策略和纠正记录。选页不改变正在运行的会话。

旧 `hil-session.json` 及配置/探活/试推理 API 保留给后端兼容工具，不参与新路线选择；后端维护新模型时应针对 policy.json 进行合同检查。历史 v15 主启动入口保留，不读取新路线用途。

复位局部停止但HIL仍存活时，页面显示“Y复位已停止”和原始原因。20261021默认右臂sender在Y后清夹爪锁存、保留右臂默认；松Y/RB、摇杆回中，再按RB接管，无需重新选臂。旧sender需先更新。当前分条合同中START不保存本条；收尾由操作者完成，松RB、等夹爪操作完成后用↑保存，不要求使用Y。

## 人工卡住时怎样继续

| 当前提示 | 操作者下一步 | 数据边界 |
|---|---|---|
| 方向受限 | 松RB、摇杆回中，再按RB改向限位内移动；不要继续向外推 | 同一条继续录制 |
| 候选方向有碰撞风险／控制暂停 | 松RB、松开其他按键、摇杆回中；等“按RB恢复控制”，重新RB并换安全方向 | 同一条继续录制，暂停区间单独标记 |
| 链路断开／等待新鲜输入 | 先恢复sender和手柄连接，再保持松RB回中；收到输入确认后重新RB | 同一条继续录制，不重放断线期间旧命令 |
| 等待机器人反馈／当前姿态未通过检查 | 本次RB没有恢复；先松RB排查，条件恢复后重新RB检查 | 暂停仍保留；不会因一直按住RB自动恢复 |
| 策略失败但显示本条仍在录制 | 释放控制后START转人工接管，再RB操作，完成后↑保存 | 仍为策略开始的同一条；这是策略转人工，不是人工暂停恢复 |
| 保护停止、正在封存／当前未录制 | 先按原始原因排障；确认保存完成后START开新条 | 前条按中断处理，不能当作续录 |

START只负责开条和策略转人工；人工暂停时反复按START不会恢复，也不会另开条。普通松RB、摇杆回中和可恢复暂停均继续记录真实观测；记录保留不代表暂停片段可直接作为训练监督。操作者完成任务和收尾后，松RB、等夹爪操作完成，再按↑保存；程序不检查是否先回位或保持固定时长。

## 状态和API

| 接口 | 作用 |
|---|---|
| GET /api/hil/routes | 后端已安装路线、三个启动命令和模型绑定就绪提示；只读 |
| GET /api/hil/state | 当前进程绑定的状态，structured 2秒过期；兼容v15日志8秒过期 |
| GET/POST /api/hil/config | 下一会话用途、任务、模型和自动视频 |
| POST /api/hil/policy/check | 健康接口，无图片 |
| POST /api/hil/policy/probe | 新三图/state单次试推理，无动作 |
| GET /api/hil/interventions | 最多100个最近派生任务 |
| GET /api/hil/video/{job}/{clip}.mp4 | 本地回放，支持Range |
| POST /api/hil/media/retry, review | 失败重试/单片段审阅，不批准训练 |
| POST /api/hil/media/claim, source, progress, upload, publish, finish | 认证worker传输协议，单租约、源与回传校验 |

原相机URL不变，增加 `X-F1-Frame-Id`、`X-F1-Frame-Age-Ms` 响应头。读缓存不递增帧身份。没有额外ROS订阅或图像编码。

structured快照为DAgger runtime/status.json，绑定PID、进程start_ticks、会话ID和时间；超过2秒或进程不符即未知。v15只读取128KiB控制台尾部，不能补造ACK、实测跟随或模型状态。详细指标和版本留在折叠诊断；相机图像是现场视野，录制帧数是已写盘证据，两者含义不同。

## 介入视频

服务器worker从完整提交会话读取片段所需图像，经三图编码后回传本机videos；本机持久任务在video-jobs。没有服务器时显示等待配置/等待服务器；控制和数采不依赖它。活动HIL/数采暂停大文件传输，服务器编码可继续。视频H.264、30fps仅为展示，保留原始图像索引与时间。

任务状态和片段审核分开。视频可播放不等于采纳，采纳不等于LeRobot训练就绪。原始数采不被修改，异常partial不自动修复/导出。后台每10秒检查完整会话manifest，活动期间不扫描；HTTP状态不读取逐帧journal。

本候选的软件/浏览器/合成视频测试与实机性能验收分开记录。已完成预览开关各10分钟的真实反馈shadow对照，约29.94Hz、写盘错误/丢弃为0；Windows手柄实机操作与ACK验收仍待现场进行。

## 急停与本次执行侧故障

2026-10-10现场会话中，接收端收到START/RB及非零摇杆，ROS发布及厂商motor_ctl接收日志均存在；14关节反馈全程完全不变，Home反馈超时。操作者随后确认误按实体急停。当前证据把问题定位在厂商驱动/控制器/硬件执行侧，不能把publisher成功或ROS新时间戳当作真实硬件跟随。

保持sender与HIL停止，按原厂现场流程解除急停、清故障与恢复使能。基础启动阻止重复节点，不是驱动复位按钮。若仍无硬件反馈更新，应检查/重新初始化原厂驱动连接；本轮不远程复位急停、不自动重启驱动或发送试探动作。

教学动画幅度已扩大；RT示意夹爪移到末端法兰外沿本地−Y安装，带掌体、两指及特写。它不是夹爪CAD或物理标定。仅修改教学表现，未提高实机遥操速度、步长或限位。

人工示教保留：用于无策略专家采集（30Hz），不同于不写训练图片的自由接入和策略纠正HIL。首页是否改为两入口尚待产品选择，不删除既有记录和导出能力。

## 结束与查看录制

当前示教与RTC-HIL统一START开始、↑保存。策略中再START接管，人工START不交还。收尾由操作者完成，松RB、等夹爪操作完成后↑结束，不要求先回位或保持两秒；若正在执行可选Y回位，须等动作结束后重新按↑，按键不排队。保存完成再整理现场、START新条，三端无需重启。空闲不写训练图像，新条重建观测与动作来源。自由接入不录制；每条原件保存与训练审核分开。完整命令及手柄表见[现场教程](http://192.0.2.1:4243/?doc=f1-startup)。

以下为旧 v18 / 策略 HIL 的整进程结束行为：

HIL流程中点击「结束并保存」（自由接入显示「结束会话」），登录沿用工作台控制码，不取得网页运动控制权。此操作结束整个当前HIL会话并停止遥操；F1原控制进程关闭输出、排空写盘队列并提交原始数据。按钮与run_id、PID及进程启动身份绑定，旧页面不能停止新会话。网页显示「正在整理」后须等待「已保存」，才跳到DATA对应记录。旧运行端不支持时，在F1运行终端按一次Ctrl+C并等待退出；单条用↑保存，START开条/策略中接管。关闭sender或网页不等于结束录制。

后端F1_DAGGER_DATA_ROOT设为独立数据根，机器人安装使用/home/user/lxl/dagger_data；demonstration与policy_hil分目录。诊断和状态仍保留原runtime；自由接入不保存训练图像。旧runtime/raw保持只读并兼容索引，无需搬动。

DATA新增F710人工示教及策略HIL分组，直接按时间读取原始三图，播放预览最高5fps（不改变30Hz采集），暂停后可拖动定位；隐藏、离屏与切页取消请求。帧接口校验索引及单帧哈希，网页不执行全量训练审计。正常提交、内容审核、训练就绪分别管理；Home和异常边界仍需导出筛选。
