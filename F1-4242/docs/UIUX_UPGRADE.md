## 数据工作流

目录支持当前目录及子目录或全部录制搜索。审核状态、日期和搜索共同作用，页码自动收敛；记录时间兼容 ISO/Unix 秒，未知值为“—”并排末尾，同时间按 ID 稳定排序。文件时间回退仍称“记录时间”。

“全选”只作用当前页；跨页及同目录筛选保留选择，换目录清空。已选清单显示当前筛选中数量、可逐条取消。删除使用平台对话框，包含对象、总大小与逐项结果。来源变化项失效；超时显示待核对，不重试，也不凭目录消失判定事务完成。

详情左右并列历史画面/时间轴和审核；文件、路径、主题默认折叠。打开时冻结筛选结果的有序队列，后台新增不插队；失效条目跳过，目录读取失败时不擅自裁剪队列。上一条、下一条、保存和保存并下一条相互独立。

保存并下一条要求同一导航、同一来源、成功保存且提交后无新编辑。最后一条留在当前记录。失败、409、超时、登录取消与切页不误翻条。服务器审核结论与本地草稿分离，徽标不把草稿当已保存；外部更新可核对后保留草稿重新确认。

草稿与回看暂停位置只存当前浏览器会话，按 ID 和来源签名隔离。旧来源草稿阻止提交，需重新读取。前进/后退使用 episode 深链，返回目录恢复筛选、页码、滚动与焦点。原图与视频各自恢复为暂停；可输入时间定位、把原图时间插入备注，不换算成实机动作区间。

## Replay 工作流与结果

进入、过期和区间变更突出检查；可对齐时突出回到起点；就绪突出开始；运行时突出该条任务的停止。断连、来源和控制会话变化清除旧检查；重连只读复查。确认弹窗及提交中不轮询更新票据；对齐完成只复查，不自动回放。打开确认暂停历史播放。

头部不可撤回边界显示“取消后续动作”，结果不宣称机械停止。局部停止限定该条当前任务，全局停止保持现有权限与合同。

执行结果在统计之前。v34 双臂、左右臂 MAE/RMS/最大偏差、关节数以及夹爪独立指标保留，统计表可直接查看；曲线折叠，点击关节可展开对应曲线。用户新增的偏差条、时间光标和双轨迹继续使用。匹配数称“反馈匹配”，不是整段覆盖率。任务用时与录制区间分别显示，不相除生成完成率。

每条录制可恢复最近报告；索引与报告失败均可只读重试。报告来源不匹配标记历史来源，不作为当前动作就绪证据。旧报告无新字段时显示“—”，不填零。

## 接口增量

| 接口/字段 | 合同 |
|---|---|
| `review.revision` | 旧侧文件按内容生成摘要，不批量改写；无审核为 `none` |
| `POST /api/data/reviews` | 必须附 `expected_review_revision` 与 `expected_source_signature`；同锁比较后原子写入 |
| 审核 409 | `SOURCE_CHANGED`、`REVIEW_CONFLICT`、`REVIEW_REFRESH_REQUIRED`，含当前 `review`；前端不丢草稿 |
| HIL/Pico `data_episode_id` | 由网关按真实目录身份解析，仅完整保存记录提供；保留原 run/id 意义 |
| HIL `process_run_id` | 来自已验证录制 manifest 的 binding，完成记录与运行进程可不同 ID |
| `status_age_s` / `status_ttl_s` | Pico 由服务端给年龄与原有效期；客户端叠加单调经过时间，不比较跨机器墙钟 |
| `GET /api/replay/reports?episode_id=…&limit=1` | 只读轻量最近结果索引，无全目录扫描；旧报告仍按 ID 读取 |
| 基础启动 | 原 POST 通过 systemd-run 非阻塞受理；GET 返回 stage/result/exit_status；受理超时为待核对，设备就绪独立 |

报告索引落盘失败只记附加错误，不改变动作结果。没有新增数据库、服务端分页、后台删除、自动重试或撤销；没有改采集格式及原件。

## 发布与回退

候选不自动上线。先核对当前 release、现场 dev 修改、任务/录制/遥操状态与配置；保存受影响文件和服务配置的实际备份，再应用发布清单。只发布经验证差异，不用开工快照覆盖整个目录。

`results/uiux-upgrade/delivery/` 提供候选源码清单、定向差异包与只读采样的 v34 代码回退包，分别记录 release、dev 和实际 HTTP 哈希。它不包含运行配置和数据；正式部署时必须重新核对并备份现场变化。正式切换仍按 [AGENTS](../AGENTS.md) 与 [SHARING](SHARING.md) 的部署流程，以部署时读取的现役版本生成独立回退副本。

切换后核对静态 HTTP 哈希、服务、只读状态以及数据 ID/来源签名。回退只恢复源码/服务入口，不改写新增数据、审核或机器人姿态。
