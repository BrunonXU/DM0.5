02 / 模型时间 τ，现实时间 t

不是把角度乘1.2，而是更早读到后面的目标

假设某关节原来在1秒内从20°匀速走到30°。1.2倍速后终点仍是30°，只是约0.833秒到达。不会把30°变成36°。

本表抽稀展示0到30共31个采样位置，即30个间隔。50个模型输出点有49个点间间隔；F1还包含从执行锚点到第0个输出点的一个间隔，完整采样时需要计入。匀速关节只是算术例子，真实启停需要平滑。

两级控制循环怎样配合？

约50Hz更新目标时，读取单调时钟、计算相位τ，再对相邻模型点插值；约250Hz输出层继续做动态约束和发布。两个循环保持各自的真实时间节奏。

为什么多推理几次不等于倍速？

缩短S只是更常生成新计划。如果轨迹相位仍每秒只前进1秒，动作时间轴没有变快。

这仍是闭环执行：下一次推理继续使用新的相机图像与实测state。倍速处理的是当次计划的未来轨迹，不是把整条示教拿来快放。

03 / 倍速也会更快消耗RTC缓冲

同样14步，时间预算变短了

已验证过的F1配置是30Hz、H50、D14/S16。若按1.2倍速消费模型点，D14覆盖的时间从467ms变成389ms。模型计算并没有因此自动变快。

完整截止耗时包括请求前后调度，不等于最新222ms请求中位数。367ms来自历史一轮的截止耗时，不能代表未来最大值。

比较方案D / S前缀时间预算重规划周期扣除耗时后余量

浅色条是承诺时间窗口，深色细条是推理与调度耗时；细条越过右侧竖线，就超过本次预算。

“保持墙钟预算”按D=ceil(14r)、S=ceil(16r)分别向上取整，只是教学候选。当前实现还要求D≤S<H−D；更大D/S会增加解码窗口，需要重新测量真实耗时。绿灯只表示本次算术预算为正，不代表部署通过。

从头以固定倍率启动最简单。中途改倍率则必须保留已经承诺的动作及其真实到达时刻，在承诺区间之后平滑换挡；不能收到新结果就从索引0重播，也不能把旧计划的时间戳全部乘新倍率。

05 / 真正写进推理框架时

先实现固定1.1倍速，再做分阶段速度

模型30Hz预测→既有EEF解码与IK→带时间的关节轨迹→执行相位 τ(t)→现有输出与跟踪
  1. 分开两只时钟，保留原模型合同。新增独立的execution_scale / 执行相位。模型仍报告30Hz、H50，所有观测与日志继续记录真实墙钟。当前协议会拒绝把frequency_hz直接改成36。
  2. 按相位采样，不缩放目标角度。固定1.1×从bootstrap开始；同一会话的计划接续使用连续相位和明确的计划原点。约250Hz输出循环、反馈新鲜度与watchdog继续按真实时间工作。
  3. RTC按真实执行日历保留承诺。把旧计划在新请求各采样时刻的绝对动作作为前缀，再按新观测锚点重表达。已经承诺的实际输出曲线与时间不能被重采样覆盖；未来后缀才采用新生成结果。
  4. 检查真实跟踪，不只检查参考曲线。固定r时速度需求乘r、加速度乘r²、jerk乘r³。若输出限额已经吃满，时间轴跑快也可能只是目标跑远了；要比较selected→submitted→measured的滞后。
  5. 再做平滑过渡和分阶段倍速。搬运段试1.1×/1.2×，接触与夹爪时机先保持原速。阶段识别与切换也要验证。G2的C1/C2连续性经验用于减少突变，不保证自动缩短任务时间。

为什么不能让倍率瞬间从1.0跳到1.2？

变速时轨迹相位是积分：τ(t)=∫r(u)du。原轨迹对τ的导数记作q′、q″、q‴，则：

速度：q̇ = r q′
加速度：q̈ = r² q″ + ṙ q′
jerk：q⃛ = r³ q‴ + 3rṙ q″ + r̈ q′

只要倍率正在变化，就会多出ṙ和r̈项。工程上应做连续过渡，并检查整条过渡轨迹的动态约束，而不是直接切换倍率。动画的分阶段计时忽略这些过渡时间。

用一小段伪代码看固定倍率采样 
# 仅解释核心采样，不是可以直接部署的控制代码
model_hz = 30
execution_scale = 1.2
# q[0]在此表示执行锚点，其后才是模型输出点

wall_elapsed = monotonic_now - plan_wall_origin
model_phase = execution_scale * wall_elapsed
index_float = model_hz * model_phase
k = floor(index_float)
u = index_float - k
q_reference = interpolate(q[k], q[k + 1], u)

为什么不会“保留了路径，就一定保持准确率”？

相同空间参考路径不等于相同实际运动。执行加快会改变惯性、接触过程、夹爪可用闭合时间和新观测中的状态分布。当前F1已有Ruckig及低通，不能默认再加一层平滑就能跟上。首轮应先离线检查，再完整负载shadow，最后现场验证到位、夹持与插入。
