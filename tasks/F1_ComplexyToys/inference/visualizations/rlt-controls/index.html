    哪些情况不响？奖励 0 又是什么意思？

    暂停不冒充接管。候选越界暂停、静止时序暂停、RTC 重新规划、RB 恢复均不播放接管音。按键未受理、重复→也不播放成功音。

    START 可多次纠正 VLA。人工交还统一回 VLA，不回 RLT；本条 RLT 机会已经使用后，不能再次进入。

    ↑是局部终点。确认正确放入并松手后按，不等撤离或复位。局部结束后再按↑，不能补造终点。

    人工接管本身不算失败。RLT→人工纠正仍属同一局部任务；按↑可记辅助成功，与自主成功分开统计。

    未评分：先确认结果，再交还或复位。局部任务仍开放时，人工 START 交还或 Y 复位被拦住，并提示↑成功／↓失败；START 接管始终允许。评分后需要再次按 START 或 Y，不会自动执行之前被拒绝的操作。异常退场保存为待审，不自动填0。中间步骤也可奖励 0，但尚未终止。已经成功却漏↑属于误标，需要审核，不能当真实失败学习。

    ↓确认失败，不是接管键。确认本次放置失败并放弃时按；人工仍保持控制，自主策略停止等待。失败不增加第七种正常音，以终端明确回执为准。断网、急停等异常按中断审核；保存音只确认记录封存，不代表任务成功。
