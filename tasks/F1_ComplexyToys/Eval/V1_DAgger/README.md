# V1＋DAgger真机复盘：能松手，仍没有稳定完成插入

**10月23日新增A两条、B四条：四段确实松手，但木块仍留在桶盖，没有确认完整任务成功。** 用户感觉B比A好一些；本轮样本少、时长不等，且一条长记录中有人重摆木块，暂不能把这种体感写成成功率优势。问题已不只是“不松手”，还包括抓取确认、精确插入和正确时机的释放。

**下一轮应补“偏差下如何对准并插入，满足条件才松手”的连续成功示教与恢复，而非继续单独提高松手权重。** 既有释放链路审计未见抽查范围内的固定错位，小样本能拟合却在独立持物状态误松；这支持优先改善示教一致性、覆盖和独立验证，尚不支持把退化单独归因于DAgger、RTC或模型容量。

本页汇总真机结果并保留首轮历史证据；[阶段采样实验](../../training/experiments/20261022-stage-sampling.md)与[释放监督诊断](../../DataPrehandle/reports/20261023-release-supervision.md)解释离线发现。旧Full1K可作现场对照，但与新模型的输入合同、统计和训练来源不同，不能把它们当成只改变DAgger数据的单变量实验。

### 与旧Full1K相比，训练实际改了什么

**新DAgger并非在旧Full1K上追加九条后继续训练。** 两轮都从官方base开始，而输入、统计与采样同时改变；旧Full1K适合作现场工作对照，不能独自回答“纠正数据有没有净收益”。

| 项目 | 旧V1 Full1K | 新DAgger1K | A1250／B1250 |
|---|---|---|---|
| 训练来源 | 12条完整V1；另3条验证 | 同12条＋同场次9条后半程纠正；另保留原3条和1条纠正验证 | 与新1K相同 |
| 有效训练窗口 | 13,102 | 18,899，其中纠正5,797 | 与新1K相同 |
| 模型输入 | 三图有效、state16 | 主图／右腕有效、右侧8维信息；左输入隔离 | 与新1K相同 |
| 权重起点 | 官方π0.5 base，全参数训练 | 官方base重新Full，新优化器 | 新DAgger1K完整断点，各续250步 |
| 采样方式 | 全窗口池shuffle，长episode曝光更多 | 每批V1／纠正96∶32，来源内先均匀episode、再均匀起点 | A不变；B仅将episode内松手临近起点权重设为4 |
| 累计窗口抽取 | V1 128,000次 | V1 96,000＋纠正32,000次 | 各V1 120,000＋纠正40,000次 |
| 归一化 | V1训练来源统计 | V1＋纠正训练来源重新拟合 | 沿新1K统计，不重算 |

各版均为global128、右EEF10、30Hz/H50及真实时间mask，保留ROI和训练随机增强；Full峰值LR为2.5e-5、warmup100、2K cosine日程，A/B沿原进度恢复。新旧主训seed也不同。完整参数见[旧Full配方](../../V1_FullSFT.md)、[新DAgger配方](../../V1_DAgger_FullSFT.md)与[A/B实验](../../training/experiments/20261022-stage-sampling.md)。

**新1K的V1曝光比旧1K少25%，但A/B1250已达旧1K的93.75%，仍未完成插入。** 这些只是重叠窗口抽取量，不是独立示教数，也不能据此断言已经充分训练。新DAgger同版固定验证loss从250步约0.0874升至1K约0.1576，再到A/B约0.189，而训练loss下降；结合A原采样续训的有限收益，目前不支持继续原数据堆步数。不同训练统计下的旧Full与新DAgger loss不可直接排名。

若要单独验证纠正监督的收益，应另设计同一单臂输入、初始化、公共训练统计、采样与预算的V1-only／V1＋纠正对照；不能两组各换统计后仍称单变量。**这是待讨论的实验，不恢复左输入A/B，也没有启动新训练。** 当前先完成旧Full1K与B的同条件现场分阶段对比。

### V2的采集与留出建议

优先建议**20条新的完整成功示教用于训练，另采5条独立验证**，覆盖木块XY、桶XY及两者组合；完整展示正确插入、释放、撤离和Home真实停稳。若总预算只有20条，则先按**16训练／4验证**划分，不能既称44条全进训练又用其中片段验证。

按16／4方案，加原V1冻结12／3和9条纠正，训练为28条完整示教＋9条纠正，共37条记录；完整验证为7条，另保留旧1条纠正验证。整条和采集场次隔离，避免相邻窗口泄漏；新验证使用不同具体摆放，并区分训练范围内留出与范围外挑战。少量验证用于发现退化，不能代替真机成功率。数量和下一轮混训仍待确认，schema4导出／reader需先完成适配。

## 同观测／同噪声对照：进一步定位（2026-10-22）

以下为10月22日首轮四模型各一条的历史分析，保留当时结论。四条均未完成完整任务，用户确认当日这四次没有人工移动桶、积木或扶臂；这一确认不延伸到10月23日新增记录。250已下调候选优先级；新1K在边界观测可解性上较好，但未成为完整任务冠军。

**新增480条四模型配对预测和108条1K去噪对照。** 18个现场观测按原observation ID精确取图，核对状态、采集时间和JPEG哈希；另选4个训练集成功释放观测作正参照。每个模型使用同样的3份新初始噪声，噪声张量SHA一致；四次同进程重复输出差为0。历史原噪声未保存，本实验不是复现现场的原随机轨迹。

### 1. RTC不是所查停滞的唯一原因

500／1K各4个停滞观测，共8个；每个checkpoint测试24个“观测×噪声”条件。以下“近期”指新生成的索引14–31，保留同一历史已承诺关节前缀；**无引导只关闭神经网络RTC引导，不是部署同步控制器**。

| 模型 | 有引导：近期张开／24 | 无引导：近期张开／24 | 无引导：近期最大平移距离中位数 | 有／无引导IK通过 |
|---|---:|---:|---:|---:|
| 250 | 0 | 0 | 2.84mm | 各24／24 |
| 500 | 0 | 0 | 5.10mm | 各24／24 |
| 625 | 0 | 0 | 5.28mm | 各24／24 |
| 1K | 0 | 0 | 4.88mm | 各24／24 |

所以这些状态下不是“模型已经给出正确的近期释放，单纯被RTC挡住”。无引导的模型仍主要预测闭爪和小幅动作。**这也不表示应该立刻释放**：现场有些积木尚未正确插入，真正缺的是继续对准、插入并完成阶段转换。仅强制松手会掩盖失败。

这项固定观测测试不能完整排除RTC对历史路径形成的影响，也不能证明关闭RTC后的整条轨迹不会变化；它只隔离当前条件下引导的作用。

### 2. 更关键：成功训练示教中，松手也预测晚了

选择2个V1、2个新纠正的训练样本，当前夹爪闭合，专家在7–9帧后张开。原图与后续0.5／1秒画面确认真实张开并让木块进入孔内；不是从失败rollout拿模型动作当真值。无随机增强、无RTC引导，训练与推理共享处理器及统计。

| 训练样本 | 专家张开时刻 | 新1K预测张开时刻（三份噪声，5步去噪） |
|---|---:|---|
| V1／919 | 0.27秒 | 0.40／0.33／0.40秒 |
| V1／1772 | 0.23秒 | 1.00／1.40／0.90秒 |
| 纠正／13508 | 0.30秒 | 1.43／1.63／1.33秒 |
| 纠正／14393 | 0.23秒 | 1.03／1.40／0.93秒 |

时刻按动作索引／30Hz换算，未另补偿曝光与控制对齐误差；不是接触力判定。

![同一成功示教观测下四checkpoint的释放时间](artifacts/counterfactual/release-timing-controls.png)

**1K确实学会了一部分，但抽查4个训练状态中还有3个明显偏晚。** 这比“只是没见过现场偏差”更直接：已见训练状态上的转折拟合也不足。抽样不是全训练集成功率，不能说所有释放都没学到，也不能由此断言网络容量不够。

[四个参照的原始右腕时序图](artifacts/counterfactual/control-images/contact.jpg)能看到专家随后释放／入孔。四样本中919只有40个有效时间步，其余均50；误差统计只计真实有效步，因此不能把共同问题归给短窗padding。

### 3. 增加去噪步数没有修复这个现象

对1K固定8个观测、3份噪声，比较5／10／20步。现场500／1K停滞观测仍保持闭爪；625释放前观测仍把释放安排在很远处。纠正13508的首次释放从5步的43／49／40帧，变为10和20步的43／48／40帧，离专家9帧仍很远。这里提高推理计算量没有带来阶段推进。

另做两次eager／compiled对照，并非逐位一致：原始动作最大差分别0.01389／0.00635。对纠正13508，夹爪开度差有上界0.318；编译预测在第43帧前最低仍为85.60，第43帧降到4.95，这个差不足以改变“第43帧才张开≤10”的判断。**因此这例约1.1秒的延后不能由所见编译误差解释。** 不将两次检查扩展为整条执行路径数值完全一致。

同时全量核对冻结训练包：所有有效时间步的夹爪标签等于`(submitted_gripper−50)/50`，不存在本轮检查所见的符号／比例翻转；padding不参加该核验。

### 4. 1K改善了局部可解性，但仍未完成任务学习

把250首次拒绝前及拒绝时的5个历史观测，各用3份噪声交给四模型，保持同一历史前缀：

| 模型 | 有RTC引导IK通过／15 | 无引导IK通过／15 |
|---|---:|---:|
| 250 | 12 | 13 |
| 500 | 12 | 14 |
| 625 | 12 | 13 |
| 1K | 15 | 15 |

这说明1K在这组条件下更容易给出可解的后续目标，可作为后续诊断参考。它不是新1K自主运行的15次成功，更不是插入／回位成功率；固定历史前缀也没有证明它自己从开头就会走同一条路径。

### 对下一轮的具体影响

以下为10月22日据首轮证据提出的计划；其中阶段采样对照已执行，当前结论与下一步以[两轮复盘](../../training/experiments/20261022-stage-sampling.md#两轮合起来能归因到哪里)为准，不将历史计划视为仍未开训。

- **不建议先换RTC、加去噪步数或只放宽IK。** 它们都不能解释并修复这里看到的训练样本释放延迟；线上配置保持。
- **优先做阶段采样的独立训练对照，先不把新增纠正总权重继续加大。** 保留V1完整流程，保留来源75∶25作为控制变量，在来源内部增加接近→插入→释放→撤离的转折窗口曝光，抑制长时间闭爪停留／终点保持对这些短阶段的稀释。具体配额需覆盖审计后确定，不在本轮直接开训。
- **先过离线阶段检查，再花现场测试时间。** 使用独立episode的阶段样本验证近期动作、释放时机、抓取保持和Home，训练集四参照只用于发现拟合问题，不能充当选模验证集。应学到动作时机与接近路径，不能把“提前张开”本身当优化目标。
- **补数据仍有价值，但先补当前失败的恢复状态，不是先盲扩数量。** 已有成功观测都学不准时，仅再加几条同姿态相似数据未必能改变有效采样；真正缺少的偏差恢复／XY覆盖另行补齐。上述结果没有证明75∶25是根因，也没有证明阶段重采样必然有效。

### 500／1K：持续生成小动作，近期闭爪；存在远期松手被重规划替换

40–60秒，每个请求新生成、可解码后缀中，相对当前FK锚点的最大平移距离，中位数约为500的4.97mm、1K的4.59mm。它们有更新、有小动作，不能把视觉上的停滞解释成服务不工作；这些数值也不是物体到孔口误差。

夹爪编码先按`clip(50×EEF第10维＋50, 0, 100)`还原；0张开、100闭合。不能直接将该维乘100当硬件开度。几个可定位的实例（索引从0开始）：

### 输入、跟随与网络：没有找到统一停机原因，但不是全链路无问题证明

- 四条577个服务请求，549成功解码、28拒绝全部来自250。记录中未发现RTC超时；三路frame ID持续递增，没有重复同一frame ID。观察间隔中位数约33.33ms，仍有79–162ms最大间隔，不能称曝光严格同步。
- 请求往返P50约230–237ms，P95约263–278ms；观测采集到回复P95约330–368ms。请求往返、观测年龄和网页预览延迟不是同一指标。
- 右臂七关节逐控制记录的提交值与反馈绝对差P95：625为0.92°、1K为0.81°、250为1.04°、500为1.45°。能排除长时间完全不执行的解释，但不能认证接触过程或所有轴的瞬态跟随。
- 抽查ROI重建图，桶、积木和右夹爪没有被裁掉。左夹爪拆除仍改变了主图外观，即使左腕图被mask，也不能认定现场与训练图像分布完全相同；当前证据不足以说它造成全部失败。
- 对训练状态范围复核：250后段J3／J7明显超出训练min/max，625也出现多轴超范围；当前模型状态归一化会clip，可能减少越界程度的信息。250首次越界发生在首次拒绝**之后**，所以不能用它解释第一次拒绝。500没有这些状态越界，仍停滞；这也不是四版统一根因。

冻结训练包18,899窗已重新统计。九条纠正5,797窗的阶段计数是：对孔／插入2,888，撤离1,573，原生Home619，终点保持717。按**来源→episode→起点**的实际采样算法折算，它们分别占全局抽样约11.55%、7.27%、2.88%、3.30%；纠正整体仍是25%，不是25%都在教插入。

**松手标签没有漏掉。** 以当前状态≥90且未来有效标签≤10定义“闭爪到张开”：V1有586个H50窗口，纠正有446个；考虑来源和episode权重，合计期望占全局抽样5.60%。前16步内就张开的窗口分别183／143个，合计约1.77%。所有统计排除时间padding，仅统计真实有效标签。

这个比例不是漏训证据，也不是某个通用最优值；窗口重叠、每窗有效长度和实际优化都会影响学习。它提示下一步可单独评估**接近→插入→释放的转折监督**，不能直接把全部25%纠正权重翻倍。统计见[有效松手监督](artifacts/release-supervision-audit.json)。

## 接下来怎么做

1. **先不自动续训，也不让用户反复替250跑完整任务。** 保留四条失败证据与权重；本次未关闭现有服务。500／1K停滞和625错位释放比继续堆步数更值得定位；旧Full1K是历史对照，不能直接声称当前仍在线。
2. **固定失败观测对照已完成，优先阶段拟合诊断。** 四模型／有无RTC、1K去噪步数与编译核验结果见上节；没有显示直接关闭RTC或增加去噪就能解决。下一轮需独立阶段验证集与受控阶段采样配方，不重复把本轮训练集参照当泛化验收。
3. **核对与专家纠正的状态差异后再定下一轮配方。** 对比持物朝向、距离、插入前后图像、闭爪→松手时机与撤离方向；优先识别现有九条是否覆盖此次偏差。若缺覆盖，补从当前失败状态开始的真实纠正及少量完整成功示教；若覆盖而预测仍错，再独立比较训练量或阶段采样。不要同时改RTC、IK、比例和步数，无法归因。

四次没有人工帮助已由用户明确确认；250的起始J3/J4/J7与其他条有数度差异，各条运行时限也不同。因此这些是**失败定位样本**，不是严格随机配对试验；不据此认定哪个版本的长期成功率更高。当前结果说明这一轮没有兑现预期收益，并不证明DAgger方法无效或V1数据作废。
