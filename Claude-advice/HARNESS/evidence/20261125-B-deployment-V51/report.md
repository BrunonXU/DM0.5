# F1 Harness 相机复核与观测补验 V51 部署验收

V51 已接替 V50。机器人端 371 个包文件和 13 个现场配置文件核验一致；4242 已连到 V51，空闲且可开始。独立 VLA 服务当时不可用，首测使用 Astra 路线。部署过程中硬件输出为零。现场摆好一块直立方块后，由操作者在 4242 点一次“开始任务”。[部署回执](deployment.json)

首测要回答的是，机器人能否从一次授权走到放置确认。若整段无人介入，且同一请求有控制端的放置成功回执，就达到 M0。避桶复位另计；若中途停止，保留最后一条技能回执和首次发布位置。固定布局的十次对照用于衡量重复成功率、时延和非物理拒绝降幅。[首轮验收指标](../../review-acceptance.md) · [历史漏斗](../20261125-A2-baseline/report.md)

## 这次部署改变了什么

- **H-01** 可选相机流增减时，按最新观测重扫同一候选。V40 实录中的左腕加流特例在 V50 已经能通过。
- **H-02** 技能提交前最长等待合格观测 15 秒，仍受当前任务期限约束。短暂缺帧后取得合格几何才能提交。
- **H-03** 控制引擎和 owner 对同一检查点可接受六次只读补验，正式程序默认自动发起两次。动作修正沿用原预算。[运行时代码与测试复验](../20261125-B-software-rerun/report.md)
