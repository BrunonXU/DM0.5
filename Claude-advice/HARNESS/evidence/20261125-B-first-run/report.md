# F1 Harness V52 首批真机记录

11 月 25 日，4242 记录了两次独立授权的 V52 现场任务。两次都完成了任务准备（S0），机械臂一直保持，技能动作首发（S1）为 0。最新一次的底层录像拍到了直立方块，但规划用的感知网关在五个观测窗口内始终返回空帧，任务在首动前结束。

## 与 Claude 建议的关系

- H-02 的 15 秒窗口已在最新真机请求上实际走完。更早的四个约 4 秒窗口用于首动前查询观测。最新请求直到 15 秒结束仍取不到帧，因此“取得观测并继续执行”仍待验收。
- H-01 处理已有动作候选在复核时可选相机发生变化。前一次停在底层录像同步，后一次连首份可用场景都没有形成，两次均早于候选复核。H-03 动作完成后的补验、H-06 运输终点、H-15 判抓和 H-07 对准也都还没走到。
- 本轮定位到任务取帧这一环。网关继承启动环境的 ROS 中间件配置，底层录像控制端显式设置 Cyclone DDS，两个入口存在可复查的差异。现场结束后复测时，既有 ARM 管理隧道 SSH 握手超时，登记的直连地址也超时，未取得可用的新样本。启动配置、原始图像发布与订阅回调哪一项导致此次空帧，仍须同条件只读取样区分。[事后只读检查](post-run-readonly.json)
