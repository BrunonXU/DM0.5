## 阶段一：只读观察，预计第 1–2 个工作日

**启动条件：** 基础交付通过，数据来源与允许读取的接口已明确，私密认证仅在本地客户端使用。

- [ ] 定义只读输入、输出和错误合同，固定最小可复现样例与评价标准。
- [ ] 建立核心独立环境并锁定传递依赖；实现 F1 registry／host 最小适配与 fake backend，不安装完整仿真和感知 extras。
- [ ] 接通已选官方模型接口，记录真实模型与配置身份；检验输入、结构化输出、超时和失败处理，日志脱敏。
- [ ] 用保存观测或只读状态完成端到端回放，核对模型判断与真实来源，避免将推断写成测量事实。
- [ ] 证明此阶段没有机器人动作发布或写控制状态；记录已通过项、失败样例和限制。

**通过条件：** 只读链路可复现，结果与来源可追查，失败明确，零动作边界有实际证据。达到后才进入几何阶段。

## 阶段二：几何接口，预计第 3–5 个工作日

**接口集成条件：** 只读阶段通过，所需相机、机器人反馈与坐标定义可用。棋盘打印、标定采集与离线几何检查可以从第一天并行，不必等待模型接口。

- [ ] 明确坐标系、单位、时间戳、有效范围与变换所有者；复用既有运动学和已验收接口。
- [ ] 准备并核验所需标定，区分实际测量、模型估计与缺失字段。
- [ ] 核验 base→右臂原生参考系→EEF／TCP→物体坐标链；建立桶／桌面／邻物及夹持物几何检查，不能用原机器人 gate 代替场景净空。
- [ ] 在保存样例和离线回放中验证几何输出、变换与可执行性检查，覆盖过期、越界和不完整输入。
- [ ] 汇总几何误差、失败分布与适用条件；暂不以离线几何结果宣称接触或任务成功。

**通过条件：** 几何合同与参考证据一致，输入异常可拒绝，误差达到实施方案规定的任务门槛；缺少真实标定时明确停留在离线结果。

## 阶段三：最小闭环，预计第 7–12 个工作日首次现场尝试

**启动条件：** 前两阶段通过，控制所有者与接口合同明确，所需现场条件具备。

- [ ] 实现最小控制网关与任务状态机，复用原控制锁、保护、取消、保持和恢复语义。
- [ ] 实现有界几何运动技能、本地视觉纠偏和场景检查；区分可恢复任务失败与撤权／硬故障。该工作预计第 4–10 日与几何验证并行，未通过则顺延现场尝试。
- [ ] 完成离线与零输出集成检查，核对计划、实际提交、反馈和结果的独立身份。
- [ ] 在实际控制所有者下，以新鲜的本地真实 START 授权进行约定范围的现场尝试。
- [ ] 留存完整观察→计划→执行→反馈证据，分别统计成功、失败、人工介入和恢复，不以单次顺利运行替代重复性验证。
- [ ] 根据真实结果决定继续扩展、修订或保留基线；部署身份与框架版本在实际登记后记录。

**通过条件：** 最小任务按实施方案完成真实闭环，异常与恢复有证据，适用范围和未通过项清楚；现场未执行时保持“待验”。
