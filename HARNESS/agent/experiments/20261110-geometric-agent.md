## 实现与证据

| 项目 | 原行为 | 本轮实现 |
|---|---|---|
| 动作表达 | 技能、连续 pitch、四个 variant | 完整 SE(3) 抓姿、接近向量、TCP终点及至多12个中间点 |
| 规划反馈 | 提交后才能看到拒绝 | 独立 preview，不提交、不产生可执行授权、不改变进度 |
| 看图 | 必须先得到有效几何观测 | 直接读取 RGB 帧，只读且不 ingest owner |
| 候选评分 | 先排 variant，再遍历 pitch | 对实际 descriptor×variant 评分，距离、转角、成功先验与视野软代价 |
| 验证恢复 | 部分读取失败丢失原验证身份 | 保留原 owner checkpoint，不伪造新完成 |
| 路点恢复 | 无此技能 | 零发布恢复进度；停滞继承目标；移动使旧对准／插入结论失效 |
| 模型连接 | 一次连接失败结束 | 确认未发送时重试一次，STOP阻止重试，分阶段计时 |
| 经验 | 参数偏好 | 保留相对抓姿经验，拒绝自动复用场景特定 TCP 路点 |
