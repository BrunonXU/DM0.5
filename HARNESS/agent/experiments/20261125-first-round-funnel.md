# F1 Harness 首轮改造与历史漏斗

106 次已授权的历史运行中，39 次出现首动发布，19 次确认抓住积木，6 次运输到位。105 次有控制端收尾的运行均缺少 S8 放置成功回执，另一次在首动后截断。首次由同一请求验证无人介入放置的 M0 仍待现场完成。

本次历史样本含多个版本和三种运行模式。部署登记可定位到 V50，现场样本中可识别的版本最晚为 V49。下一次按固定布局记录 V50 和候选的前后结果，优先核对首动、对准和放置，避桶复位单列。[A-2 逐项统计](../../../Claude-advice/HARNESS/evidence/20261125-A2-baseline/report.md)

## 开始前的证据

129 个目录全量扫描，23 个缺少控制端记录。两端记录可配对的样本中，实测授权到首动的中位数为 22.95 秒，统计分母是实际出现首动的 39 次。两次运行若使用不同版本或布局，分别保留记录和适用范围。[原始记录与抽查](../../../Claude-advice/HARNESS/evidence/20261125-A2-baseline/manifest.json)

控制端记录了 42 次因非物理原因零发布的失败。用户确认原因模糊时按 Claude 提议的口径计入非物理；相机身份变化和端点偏差各保留一条实例供复核。候选阶段沿用同一张分类表，在相同布局与次数上比较。[分类与依据](../../scripts/funnel_reasons.json)
