# F1 Harness 首轮改造与历史漏斗

从已部署的 V50 分出候选后，H-01、H-02、H-03 已分别提交。正常程序在内存回放中完成放置和复位。全量测试有三条仍按旧的 4 秒观测窗口验收，按用户要求保留这些差异。软件门票尚未通过，本轮真机试验尚未开始。[候选验收报告](../../../Claude-advice/HARNESS/evidence/20261125-B-software/report.md)

历史的 106 次运行中，39 次出现首动发布，19 次确认抓住积木，6 次运输到位。105 次有控制端收尾的运行均缺少 S8 放置回执，另一次在首动后截断。样本跨三个运行模式，能识别的现场版本最晚为 V49。同布局 V50 对照和首次由同一请求验证无人介入放置的 M0 都待现场完成。[A-2 逐项统计](../../../Claude-advice/HARNESS/evidence/20261125-A2-baseline/report.md)

## 开始前的证据

129 个目录全量扫描，23 个缺少控制端记录。两端记录可配对的样本中，实测授权到首动的中位数为 22.95 秒，统计分母是实际出现首动的 39 次。两次运行若使用不同版本或布局，分别保留记录和适用范围。[原始记录与抽查](../../../Claude-advice/HARNESS/evidence/20261125-A2-baseline/manifest.json)

控制端记录了 42 次因非物理原因零发布的失败。用户确认原因模糊时按 Claude 提议的口径计入非物理；相机身份变化和端点偏差各保留一条实例供复核。候选阶段沿用同一张分类表，在相同布局与次数上比较。[分类与依据](../../scripts/funnel_reasons.json)
